Todos los placeholders están escritos enteros, y al hacer clic en uno se copia.

## El clan del espectador

<Callout type="note" title="Dos líneas de messages.yml deciden cómo se ve la ausencia">
Aquí nada resuelve nunca a una cadena vacía. Un jugador sin clan, un hueco de plantilla vacío y un clan
sin clasificar responden todos con una palabra configurable:

| Clave | Viene como | La usan |
|---|---|---|
| `placeholders.none` | `{muted}None` | `clan_name`, `clan_role` |
| `placeholders.na` | `{muted}N/A` | Huecos vacíos de la plantilla, posiciones sin clasificar |

Las dos viven en `messages.yml`, bajo `placeholders`, junto a las palabras que usan los menús.
Cámbialas ahí y cada placeholder de esta página las sigue.
</Callout>

| Placeholder | Descripción |
|---|---|
| `%exyliaclans_clan_name%` | El nombre del clan, o `placeholders.none` |
| `%exyliaclans_clan_id%` | Su id, o vacío |
| `%exyliaclans_clan_members%` | Miembros totales |
| `%exyliaclans_clan_online%` | Miembros conectados |
| `%exyliaclans_clan_max_members%` | El tope, con el bonus de nivel incluido |
| `%exyliaclans_clan_balance%` | El banco, formateado |
| `%exyliaclans_clan_role%` | El nombre del rango del espectador, o `placeholders.none` |
| `%exyliaclans_clan_is_leader%` | `true` / `false` |
| `%exyliaclans_clan_ff%` | Friendly fire, `true` / `false` |
| `%exyliaclans_clan_allies%` | Número de clanes aliados |
| `%exyliaclans_clan_kills%` | Bajas del clan |
| `%exyliaclans_clan_deaths%` | Muertes del clan |
| `%exyliaclans_clan_kdr%` | KDR del clan, dos decimales |
| `%exyliaclans_clan_playtime%` | Tiempo jugado total, formateado |
| `%exyliaclans_clan_level%` | Nivel del clan. Un jugador sin clan lee `1`, no `0` |
| `%exyliaclans_clan_exp%` | EXP actual |
| `%exyliaclans_clan_exp_next%` | EXP que falta para el siguiente nivel |
| `%exyliaclans_clan_mail_unread%` | Correo sin leer de este espectador |
| `%exyliaclans_has_clan%` | `true` / `false` |

## La lista de conectados

Hasta **treinta** huecos en cada una, ordenados por peso de rango — el más pesado primero — y luego
alfabéticamente. Un hueco sin nadie responde con `placeholders.na`, que viene como `{muted}N/A`.
Cambia `<n>` por el número de hueco, de `1` a `30`.

| Placeholder | Descripción |
|---|---|
| `%exyliaclans_clan_online_member_<n>%` | El nombre del jugador |
| `%exyliaclans_clan_online_member_<n>_role%` | El nombre de su rango |
| `%exyliaclans_clan_online_member_<n>_kills%` | Sus bajas en ese clan |
| `%exyliaclans_clan_online_member_<n>_deaths%` | Sus muertes en ese clan |
| `%exyliaclans_clan_online_member_<n>_kdr%` | Su KDR, dos decimales |
| `%exyliaclans_clan_online_ally_<n>%` | El nombre del jugador aliado |
| `%exyliaclans_clan_online_ally_<n>_role%` | El nombre de su rango |
| `%exyliaclans_clan_online_ally_<n>_kills%` | Sus bajas en ese clan |
| `%exyliaclans_clan_online_ally_<n>_deaths%` | Sus muertes en ese clan |
| `%exyliaclans_clan_online_ally_<n>_kdr%` | Su KDR, dos decimales |
| `%exyliaclans_clan_online_ally_<n>_clan%` | De qué clan es |

```
%exyliaclans_clan_online_member_3_kdr%
%exyliaclans_clan_online_ally_1_clan%
```

La lista se reconstruye como mucho una vez por segundo, así que treinta líneas de scoreboard pidiendo
cuatro veces por segundo cuestan una reconstrucción.

## Rankings

Claves válidas: `online`, `members`, `kills`, `deaths`, `kdr`, `playtime`, `balance`. Lo que no esté
clasificado devuelve `placeholders.na`.

| Placeholder | Descripción |
|---|---|
| `%exyliaclans_clan_leaderboard_rank_<stat>%` | En qué puesto está el clan del espectador, desde `1` |
| `%exyliaclans_clan_leaderboard_top_<n>_<stat>%` | El nombre del clan en la posición `<n>` |
| `%exyliaclans_clan_leaderboard_top_value_<n>_<stat>%` | Su valor ahí, formateado |

```
%exyliaclans_clan_leaderboard_rank_kills%
%exyliaclans_clan_leaderboard_top_1_balance%
%exyliaclans_clan_leaderboard_top_value_1_balance%
```

Cada ranking se cachea 30 segundos.

## Relacionales

Estos toman un espectador **y** un objetivo, así que su sitio son los nametags, el orden de TAB y
cualquier punto donde se dibuja a un jugador para otro.

| Placeholder | Descripción |
|---|---|
| `%rel_exyliaclans_player_type%` | La etiqueta de la relación |
| `%rel_exyliaclans_player_color%` | El color de esa relación |
| `%rel_exyliaclans_player_priority%` | `5` líder propio, `4` del clan, `3` líder aliado, `2` aliado, `1` rival, `0` desconocido |

`player_priority` está hecho para ordenar una lista: cuanto más alto, más arriba.

```yaml
relational-placeholders:
  label-member: MIEMBRO
  label-ally: ALLY
  label-enemy: ENEMY
  label-none: NADA
  color-member: "&a"
  color-ally: "&b"
  color-enemy: "&c"
  color-none: "&7"
```

<Callout type="warning" title="Dos etiquetas vienen en español y dos en inglés">
`label-member` viene como `MIEMBRO` y `label-none` como `NADA`, mientras que las otras dos están en
inglés. Corra en el idioma que corra tu servidor, este bloque hay que editarlo el primer día.
</Callout>

## Formatos y respaldos

Todos los placeholders de aquí aceptan la sintaxis compartida de formato y respaldo:

```
%exyliaclans_clan_balance:comma%      1,250,000
%exyliaclans_clan_kills:compact%      12.4k
%exyliaclans_clan_ff:yesno%           Yes
%exyliaclans_clan_name|Sin clan%      respaldo cuando no hay valor
```

Formatos disponibles: `comma`, `compact` / `short`, `percent`, `upper`, `lower`, `yesno`, `time`,
`fixed1`, `fixed2`.

<Callout type="tip" title="Un placeholder que nadie responde se queda en pantalla">
Es a propósito: una errata sale como `%exyliaclans_clan_nmae%` en vez de como un hueco en blanco, y se
avisa una vez por consola con el nombre que no se pudo resolver. Si una línea del scoreboard sale vacía,
mira la consola antes que el nombre.
</Callout>
