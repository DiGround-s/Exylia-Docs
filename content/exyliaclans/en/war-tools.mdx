---
title: "War tools"
description: "Focus, camp, rally and regroup: the four things a clan points at something, and the boss bars that track them."
---

Four commands exist for the fight itself. None of them needs a rank permission except `/clan regroup`,
which needs `REGROUP` — the other three are open to any member.

## Focus

```
/clan focus <player>
```

Marks one enemy for the whole clan: they are painted **red and glowing**, for every online member, and a
boss bar shows their health. It is how a clan calls a target in the middle of a fight without typing a
name into chat.

| Refused when | Message |
|---|---|
| The target is you | `errors.cannot-target-self` |
| The target is in your clan | `errors.cannot-target-own-clan` |
| The target is in an allied clan | `errors.cannot-target-ally` |

```yaml
bossbars:
  focus:
    enabled: true
    config:
      text: "{warning}⚔ %player%  {error}❤ %health%/%max_health%"
      color: RED
      style: NOTCHED_20
```

Clearing a focus repaints the target for each viewer according to the visibility rules, so they go back
to whatever colour they should have been — not to whatever colour they had before.

## Camp

```
/clan camp <clan>
```

Puts a marker on another clan's **home**, for your whole clan: a red waypoint on clients that draw them,
and a boss bar counting the distance down. Running it again on the same clan clears the marker.

It is refused if that clan has no home set. It is not restricted to rivals — you can camp anyone.

```yaml
bossbars:
  camp:
    enabled: true
    max-distance: 500
    duration-seconds: 0
    config:
      text: "{error}⚔ Camp: {highlight}%label%  {muted}%distance% blocks  %x%, %y%, %z%"
      color: RED
      style: PROGRESS
```

`max-distance` is where the bar reads empty, not a range limit. `duration-seconds: 0` means the camp
marker never expires on its own.

## Rally

```
/clan rally
```

Drops a marker at your feet for the whole clan — yellow waypoint, yellow bar, coordinates broadcast in
chat. It is a "come here", not a teleport: nobody is moved.

```yaml
bossbars:
  rally:
    enabled: true
    max-distance: 500
    duration-seconds: 120
    config:
      text: "{success}⚑ Rally  {muted}%distance% blocks  %x%, %y%, %z%"
      color: YELLOW
      style: PROGRESS
```

A rally expires after `duration-seconds` (120 s) and the clan is told when it does.

## Regroup

```
/clan regroup
/clan regroup join
```

The teleport version. `/clan regroup` needs the `REGROUP` rank permission and broadcasts a **clickable**
message to the whole clan; clicking it — or typing `/clan regroup join` — walks the member through a
warmup and then teleports them to the point.

| Setting | Default | What it does |
|---|---|---|
| `regroup-warmup-seconds` | 5 | Countdown before the teleport. `0` is instant. |
| `regroup-cancel-on-move` | `true` | Moving cancels it |
| `regroup-cancel-on-damage` | `true` | Taking damage cancels it |
| `regroup-warmup-tick-sound` | `UI_BUTTON_CLICK\|0.6\|1.3` | Played each second. Blank for silence. |
| `regroup-cooldown-seconds` | 60 | Per clan, between calls. `0` disables. |
| `regroup-expire-seconds` | 60 | How long the point stays joinable. `0` never expires. |

The countdown is drawn by `regroup-effects`, and a member still in the warmup when the point expires is
stopped rather than teleported.

```yaml
regroup-effects:
  warmup-actionbar:
    text: "{primary}⚑ Regroup {muted}| {primary}Teleporting in {highlight}%time%"
  warmup-title:
    title: "{highlight}%time%"
    subtitle: "{muted}Don't move!"
    fade-in: 0
    stay: 10
    fade-out: 0
  teleport-title:
    title: "{primary}&lREGROUP"
    subtitle: "{muted}You joined the regroup!"
    fade-in: 10
    stay: 50
    fade-out: 15
```

`%time%` is the seconds left. Timings are in ticks: twenty to a second.

<Callout type="note" title="Rally and regroup are two different things">
Rally is a marker anyone can drop and nobody is moved by. Regroup is a teleport, gated on a rank
permission and a clan-wide cooldown. A clan can have both up at once.
</Callout>

## The clan home

Not a war tool as such, but it shares the machinery. `/clan home` runs the same kind of warmup, drawn by
`home-effects`, with `home-warmup-seconds`, `home-cancel-on-move`, `home-cancel-on-damage` and
`home-warmup-tick-sound` in `settings`. The home is also a permanent waypoint for members and allies.

## Turning the bars off

Each of the three boss bars has its own `enabled`. Turning one off leaves the waypoint and the chat
broadcast in place — only the bar goes.

| Key | Accepts |
|---|---|
| `color` | `PINK`, `BLUE`, `RED`, `GREEN`, `YELLOW`, `PURPLE`, `WHITE` |
| `style` | `PROGRESS`, `NOTCHED_6`, `NOTCHED_10`, `NOTCHED_12`, `NOTCHED_20` |
