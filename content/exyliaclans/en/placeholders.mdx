## The viewer's clan

| Placeholder | Description |
|---|---|
| `%exyliaclans_clan_name%` | The clan's name, or `None` |
| `%exyliaclans_clan_id%` | Its id, or empty |
| `%exyliaclans_clan_members%` | Total members |
| `%exyliaclans_clan_online%` | Members online |
| `%exyliaclans_clan_max_members%` | The cap, level bonus included |
| `%exyliaclans_clan_balance%` | The bank, formatted |
| `%exyliaclans_clan_role%` | The viewer's rank name |
| `%exyliaclans_clan_is_leader%` | `true` / `false` |
| `%exyliaclans_clan_ff%` | Friendly fire, `true` / `false` |
| `%exyliaclans_clan_allies%` | Number of allied clans |
| `%exyliaclans_clan_kills%` | Clan kills |
| `%exyliaclans_clan_deaths%` | Clan deaths |
| `%exyliaclans_clan_kdr%` | Clan KDR, two decimals |
| `%exyliaclans_clan_playtime%` | Total clan playtime, formatted |
| `%exyliaclans_clan_level%` | Clan level, `0` with no clan |
| `%exyliaclans_clan_exp%` | Current EXP |
| `%exyliaclans_clan_exp_next%` | EXP needed for the next level |
| `%exyliaclans_clan_mail_unread%` | Unread mail for this viewer |
| `%exyliaclans_has_clan%` | `true` / `false` |

## The online roster

Up to **thirty** slots each, sorted by rank weight — heaviest first — then alphabetically. A slot with
nobody in it resolves to nothing, so the fallback syntax is worth using. Replace `<n>` with the slot
number, from `1` to `30`.

| Placeholder | Description |
|---|---|
| `%exyliaclans_clan_online_member_<n>%` | The player's name |
| `%exyliaclans_clan_online_member_<n>_role%` | Their rank name |
| `%exyliaclans_clan_online_member_<n>_kills%` | Their kills in that clan |
| `%exyliaclans_clan_online_member_<n>_deaths%` | Their deaths in that clan |
| `%exyliaclans_clan_online_member_<n>_kdr%` | Their KDR, two decimals |
| `%exyliaclans_clan_online_ally_<n>%` | The allied player's name |
| `%exyliaclans_clan_online_ally_<n>_role%` | Their rank name |
| `%exyliaclans_clan_online_ally_<n>_kills%` | Their kills in that clan |
| `%exyliaclans_clan_online_ally_<n>_deaths%` | Their deaths in that clan |
| `%exyliaclans_clan_online_ally_<n>_kdr%` | Their KDR, two decimals |
| `%exyliaclans_clan_online_ally_<n>_clan%` | Which clan they are from |

```
%exyliaclans_clan_online_member_3_kdr%
%exyliaclans_clan_online_ally_1_clan%
```

The roster is rebuilt at most once a second, so thirty scoreboard lines asking four times a second cost
one rebuild.

## Leaderboards

Valid stat keys: `online`, `members`, `kills`, `deaths`, `kdr`, `playtime`, `balance`. Anything
unranked returns `-`.

| Placeholder | Description |
|---|---|
| `%exyliaclans_clan_leaderboard_rank_<stat>%` | Where the viewer's clan sits, `1` upwards |
| `%exyliaclans_clan_leaderboard_top_<n>_<stat>%` | The name of the clan at position `<n>` |
| `%exyliaclans_clan_leaderboard_top_value_<n>_<stat>%` | Its value there, formatted |

```
%exyliaclans_clan_leaderboard_rank_kills%
%exyliaclans_clan_leaderboard_top_1_balance%
%exyliaclans_clan_leaderboard_top_value_1_balance%
```

Each ranking is cached for 30 seconds.

## Relational

These take a viewer **and** a target, so they belong in nametags, TAB sorting and anywhere one player is
being drawn to another.

| Placeholder | Description |
|---|---|
| `%rel_exyliaclans_player_type%` | The label for the relation |
| `%rel_exyliaclans_player_color%` | The colour for it |
| `%rel_exyliaclans_player_priority%` | `5` own leader, `4` clanmate, `3` ally leader, `2` ally, `1` rival, `0` stranger |

`player_priority` is built for sorting a name-sorted list: higher floats to the top.

```yaml
relational-placeholders:
  label-member: MIEMBRO
  label-ally: ALLY
  label-enemy: ENEMY
  label-none: NADA
  color-member: "&a"
  color-ally: "&b"
  color-enemy: "&c"
  color-none: "&7"
```

<Callout type="warning" title="Two of the shipped labels are Spanish">
`label-member` ships as `MIEMBRO` and `label-none` as `NADA`, while the other two are English. Whichever
language your server runs in, this block wants editing on day one.
</Callout>

## Formats and fallbacks

Every placeholder here accepts the shared format and fallback syntax:

```
%exyliaclans_clan_balance:comma%      1,250,000
%exyliaclans_clan_kills:compact%      12.4k
%exyliaclans_clan_ff:yesno%           Yes
%exyliaclans_clan_name|No clan%       fallback when there is no value
```

Available formats: `comma`, `compact` / `short`, `percent`, `upper`, `lower`, `yesno`, `time`, `fixed1`,
`fixed2`.

<Callout type="tip" title="A placeholder nothing answers stays on screen">
That is deliberate: a typo shows up as `%exyliaclans_clan_nmae%` rather than as a blank space, and it is
reported once in the console with the name it could not resolve. If a scoreboard line looks empty, check
the console before checking the name.
</Callout>
