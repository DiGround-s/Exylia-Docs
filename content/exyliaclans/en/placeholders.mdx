The identifier is `exyliaclans`, so every name below can be written as `%exyliaclans_<name>%`.

<Callout type="note" title="PlaceholderAPI is optional">
Inside another Exylia plugin's config the bare name resolves on its own — `%clan_name%` — because
ExyliaLib owns the registry and PlaceholderAPI is a bridge on top of it. Outside the ecosystem, write the
full `%exyliaclans_clan_name%`, which asks this plugin and nobody else.
</Callout>

## The viewer's clan

| Placeholder | Returns |
|---|---|
| `clan_name` | The clan's name, or `None` |
| `clan_id` | Its id, or empty |
| `clan_members` | Total members |
| `clan_online` | Members online |
| `clan_max_members` | The cap, level bonus included |
| `clan_balance` | The bank, formatted |
| `clan_role` | The viewer's rank name |
| `clan_is_leader` | `true` / `false` |
| `clan_ff` | Friendly fire, `true` / `false` |
| `clan_allies` | Number of allied clans |
| `clan_kills` | Clan kills |
| `clan_deaths` | Clan deaths |
| `clan_kdr` | Clan KDR, two decimals |
| `clan_playtime` | Total clan playtime, formatted |
| `clan_level` | Clan level, `0` with no clan |
| `clan_exp` | Current EXP |
| `clan_exp_next` | EXP needed for the next level |
| `clan_mail_unread` | Unread mail for this viewer |
| `has_clan` | `true` / `false` |

### Across the alliance

| Placeholder | Returns |
|---|---|
| `clan_allies_total_members` | Members summed over every allied clan |
| `clan_allies_total_online` | Of those, how many are online |
| `clan_allies_total_max_members` | Their caps summed |

## DTR

| Placeholder | Returns |
|---|---|
| `clan_dtr` | Current DTR, two decimals |
| `clan_dtr_max` | The maximum, two decimals |
| `clan_dtr_state` | `NORMAL`, `FROZEN`, `REGENERATING` or `RAIDABLE` |
| `clan_dtr_color` | The colour configured for that state |
| `clan_raidable` | `true` / `false` |

```
%exyliaclans_clan_dtr_color%%exyliaclans_clan_dtr%/%exyliaclans_clan_dtr_max%
```

## The online roster

Up to **thirty** slots each, sorted by rank weight — heaviest first — then alphabetically. A slot with
nobody in it resolves to nothing, so the fallback syntax is worth using.

```
%exyliaclans_clan_online_member_<n>%
%exyliaclans_clan_online_member_<n>_<field>%
%exyliaclans_clan_online_ally_<n>%
%exyliaclans_clan_online_ally_<n>_<field>%
```

| `<field>` | Returns |
|---|---|
| *(omitted)* | The player's name |
| `role` | Their rank name |
| `kills` | Their kills in that clan |
| `deaths` | Their deaths in that clan |
| `kdr` | Their KDR, two decimals |
| `clan` | Which clan they are from — only meaningful for `ally` |

```
%exyliaclans_clan_online_member_3_kdr%
%exyliaclans_clan_online_ally_1_clan%
```

The roster is rebuilt at most once a second, so thirty scoreboard lines asking four times a second cost
one rebuild.

## Leaderboards

Valid stat keys: `online`, `members`, `kills`, `deaths`, `kdr`, `playtime`, `balance`. Anything
unranked returns `-`.

| Placeholder | Returns |
|---|---|
| `clan_leaderboard_rank_<stat>` | Where the viewer's clan sits, `1` upwards |
| `clan_leaderboard_top_<n>_<stat>` | The name of the clan at position `<n>` |
| `clan_leaderboard_top_value_<n>_<stat>` | Its value there, formatted |

```
%exyliaclans_clan_leaderboard_rank_kills%
%exyliaclans_clan_leaderboard_top_1_balance%
%exyliaclans_clan_leaderboard_top_value_1_balance%
```

Each ranking is cached for 30 seconds.

## Relational

These take a viewer **and** a target, so they belong in nametags, TAB sorting and anywhere one player is
being drawn to another. Through PlaceholderAPI they are written `%rel_exyliaclans_…%`.

| Placeholder | Returns |
|---|---|
| `player_type` | The label for the relation |
| `player_color` | The colour for it |
| `player_priority` | `5` own leader, `4` clanmate, `3` ally leader, `2` ally, `1` rival, `0` stranger |

`player_priority` is built for sorting a name-sorted list: higher floats to the top.

```yaml
relational-placeholders:
  label-member: MIEMBRO
  label-ally: ALLY
  label-enemy: ENEMY
  label-none: NADA
  color-member: "&a"
  color-ally: "&b"
  color-enemy: "&c"
  color-none: "&7"
```

<Callout type="warning" title="Two of the shipped labels are Spanish">
`label-member` ships as `MIEMBRO` and `label-none` as `NADA`, while the other two are English. Whichever
language your server runs in, this block wants editing on day one.
</Callout>

## Formats and fallbacks

Every placeholder here goes through ExyliaLib's registry, so the shared syntax applies:

```
%exyliaclans_clan_balance:comma%      1,250,000
%exyliaclans_clan_kills:compact%      12.4k
%exyliaclans_clan_ff:yesno%           Yes
%exyliaclans_clan_name|No clan%       fallback when there is no value
```

Available formats: `comma`, `compact` / `short`, `percent`, `upper`, `lower`, `yesno`, `time`, `fixed1`,
`fixed2`.

<Callout type="tip" title="A placeholder nothing answers stays on screen">
That is deliberate: a typo shows up as `%exyliaclans_clan_nmae%` rather than as a blank space, and it is
reported once in the console with the name it could not resolve. If a scoreboard line looks empty, check
the console before checking the name.
</Callout>
