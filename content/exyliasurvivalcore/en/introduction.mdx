title: "Introduction"
description: "What ExyliaSurvivalCore is: thirty-two modules on one plugin, each one switchable, each one registering nothing when it is off."
---

ExyliaSurvivalCore is the survival server in one jar. Homes, warps, TPA, random teleport, kits, crates,
mines, bounties, loot chests, power-ups, rankup, farming milestones, AFK zones, regenerating zones and
twenty more, each of them a **module** you switch on or off in `config.yml`.

A module that is off registers nothing at all: no commands, no listeners, no database tables, no
placeholders. Turning one off is not a flag the code checks in a hundred places — it is a feature that
never loads.

It is **thirty-two modules, fifty-eight menus, thirty-one database tables and two hundred and
thirty-two menu actions**, and almost everything an administrator configures is edited from an in-game
screen rather than a file.

## How a server is set up

<Steps>
  <Step title="Turn off what you do not want">
    All thirty-two ship as `true`. Set the ones you do not need to `false` in `config.yml` and restart
    — module switches are the one thing a reload does not pick up.
  </Step>
  <Step title="Set the spawn">
    `/spawn set`. The spawn module can also force players there on first join, on every join and on
    respawn.
  </Step>
  <Step title="Build the content from menus">
    Mines, crates, warps, kits, loot chests, portals, jump pads, power-ups, AFK zones and regen zones
    are all built from admin screens and stored in the database. There is no list to hand-edit.
  </Step>
  <Step title="Write the ladders in YAML">
    Ranks, playtime rewards, farming categories, kill rewards, RTP worlds, repair groups, join groups
    and the stat list are files, because they are ladders rather than objects.
  </Step>
</Steps>

## At a glance

| | |
|---|---|
| Version documented | 1.1.2 |
| Minecraft | 1.21+ |
| Platforms | Spigot, Paper and Folia |
| Required | `ExyliaLib`, `FastAsyncWorldEdit`, `packetevents` |
| Optional | `PlaceholderAPI`, `WorldGuard`, `Apollo`, `FeatherServerAPI`, an economy plugin, the `Worlds` plugin on Folia |
| Database | H2 by default; MySQL, MariaDB, PostgreSQL and MongoDB through ExyliaLib |

says something does not work, that is because the code does not do it.
