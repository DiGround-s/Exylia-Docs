ExyliaStaff is a moderation toolkit for a server or a network. It is built as sixteen modules on
ExyliaLib, each one switchable from `config.yml`, each one with its own files under `modules/<id>/`:
a staff mode with a hotbar of tools, a packet-level vanish with rank levels, a freeze for screenshares,
silent inventory mirrors, staff teleports, x-ray vision, a staff chat across servers, a global-chat
bypass, reports, help requests, a punishment ladder, an x-ray suspicion detector, a staff list, a staff
log and an admin panel that investigates the team.

Everything a staff member does on duty leaves a trail: the log counts time and actions per session,
the audit records every command, and the admin panel turns both into a team board, a risk score and
a coverage grid. A module that is off registers nothing: no commands, no listeners, no tables.

## How it is organised

**Getting started** installs the plugin and walks through a first shift. **Modules** has one page per
feature: what it does, its file, its commands and its rules. **Reference** collects every command,
permission and placeholder, the core files, the API and the questions that come up most.

<Callout type="note" title="Where the numbers come from">
Every default, message and rule on these pages was read from the plugin's source at version 1.1.0.
Where a page says a value is not configurable, that is because no key exists for it.
</Callout>
