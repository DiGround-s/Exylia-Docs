Every placeholder below is written in full, and clicking one copies it.

## Two spellings

Inside this plugin's own files, the sidebars, the menus and the messages, a placeholder is written
with the group `staff` and nothing in front of it:

```text
%staff_reports_open%
```

Through PlaceholderAPI the plugin name goes in front. The group stays in the name either way:

```text
%exyliastaff_staff_reports_open%
```

Every value is a memory read; nothing here touches the database. A placeholder of a module that is
off answers nothing.

## Core

| Placeholder | Value |
|---|---|
| `%staff_mode%` | `true` while the viewer is in staff mode. |
| `%staff_vanished%` | `true` while vanished. |
| `%staff_frozen%` | `true` while frozen. |
| `%staff_online%` | Players with `exyliastaff.staff` on this server. |
| `%staff_in_mode%` | Players in staff mode on this server. |
| `%staff_modules_enabled%` | Modules running. |

## In the sidebars

The default staff sidebar mixes these with the library's server placeholders: `%server_tps%`,
`%server_mspt%`, `%server_cpu_process:percent%`, `%server_ram_used%`, `%server_online%` and
`%player_ping%`. Turning off the reports, helpop or vanish module leaves its placeholder unresolved
on the board; edit the line out.
