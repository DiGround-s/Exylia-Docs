---
title: "Commands"
description: "Every command of every module, with its aliases, its arguments and its permission."
---

Commands belong to modules. A module that is off has none of its commands on the server: `/freeze`
with freeze disabled is an unknown command, not a refusal. Toggling a module with `/exyliastaff module`
re-registers the set and refreshes every client's command list.

`<player>` is required, `[player]` optional. A player argument is an online player by exact name,
except where a page says the server only needs to have seen them.

## Core

| Command | Permission | What it does |
|---|---|---|
| `/exyliastaff` | `exyliastaff.admin` | Lists the modules and their state. `/es` is an alias. |
| `/exyliastaff reload` | `exyliastaff.admin.reload` | Reloads every file, the modules and the command gate. |
| `/exyliastaff modules` | `exyliastaff.admin.modules` | The same list. |
| `/exyliastaff module enable <id>` | `exyliastaff.admin.modules` | Switches a module on, and its commands with it. |
| `/exyliastaff module disable <id>` | `exyliastaff.admin.modules` | Off, together with every module that depends on it. |
| `/exyliastaff redis` | `exyliastaff.admin` | This server's id, whether Redis is connected, and its stats. |

The root itself needs `exyliastaff.admin`. All of it works from the console.

## Staff mode

| Command | Permission | What it does |
|---|---|---|
| `/staff [player]` | `exyliastaff.staffmode` | Toggles staff mode. `/staffmode` and `/mod` are aliases; `toggle`, `on` and `off` are subcommands. |
| `/staff spectator` | `exyliastaff.staffmode` | Spectator view. `/staff spec` is the same. |

Another player needs `exyliastaff.staffmode.others`.

## Vanish

| Command | Permission | What it does |
|---|---|---|
| `/vanish [player]` | `exyliastaff.vanish` | Toggles. `/v` is an alias; `on` and `off` set it. |

Another player needs `exyliastaff.vanish.others` and a level at least theirs.

## Teleport

| Command | Permission | What it does |
|---|---|---|
| `/tp <player> [destination]` | `exyliastaff.teleport` | To a player anywhere on the network, or one player to another here. `/teleport`, `/stafftp`, `/tpto`. |
| `/stafftphere <player>` | `exyliastaff.teleport.here` | Brings them. `/tphere`. |
| `/staffrtp [reset]` | `exyliastaff.teleport.random` | Random player, or clear the visited list. `/staffrandomtp`. |
| `/phase` | `exyliastaff.teleport.phase` | Through the wall. `/staffphase`. |
| `/jumpto` | `exyliastaff.teleport.phase` | On top of what you look at. `/staffjump`. |

## Punishments and mining

| Command | Permission | What it does |
|---|---|---|
| `/punish <player> [reason-id]` | `exyliastaff.punish` | The menu, or an immediate punishment. A player the server has seen. |
| `/history <player>` | `exyliastaff.punish.history` | `/phistory`. |
| `/mining [on\|off]` | `exyliastaff.mining.alerts` | Toggles or sets alerts. `/notifications`, `/xraynotify`. |
| `/mining top` | `exyliastaff.mining.view` | Most suspicious miners. |
| `/mining view <player>` | `exyliastaff.mining.view` | One record, online or not. |
| `/mining reset <player>` | `exyliastaff.mining.reset` | |

## Log and panel

| Command | Permission | What it does |
|---|---|---|
| `/stafflog [player] [days]` | `exyliastaff.stafflog` | Sessions. Somebody else needs `.others`. |
| `/stafflog summary [player]` | `exyliastaff.stafflog` | 7 and 30 day totals. |
| `/stafflog top [days]` | `exyliastaff.stafflog.others` | The ranking. |
| `/staffadmin [player]` | `exyliastaff.admin.panel` | The hub, or a file. `/sadmin`. |
| `/staffadmin online`, `team`, `audit`, `coverage` | `exyliastaff.admin.panel` | Straight to a screen. |
| `/staffadmin modules` | `exyliastaff.admin.modules` | The switches. |
