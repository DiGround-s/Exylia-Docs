## Comandos de administración

Todo lo de abajo necesita `exyliapractice.admin`.

| Comando | Qué hace |
|---|---|
| `/exyliapracticecore`, `/epc` | Abre el menú de administración |
| `/epc reload` | Recarga los configs, rangos, objetos de lobby y menús de este plugin |

### Boosts de ELO

| Comando | Qué hace |
|---|---|
| `/epc boost add <jugador> <multiplicador> <duración>` | Concede un boost personal |
| `/epc boost remove <jugador>` | Lo cancela |
| `/epc boost info <jugador>` | Lo muestra |
| `/epc boost global add <multiplicador> <duración>` | Concede uno para todo el servidor |
| `/epc boost global remove` | Lo cancela |
| `/epc boost global info` | Lo muestra |

Las duraciones son `1d`, `12h`, `30m`, `90s`, o combinaciones como `1d12h`. El multiplicador tiene que
ser mayor que 1.

### Estadísticas

| Comando | Qué hace |
|---|---|
| `/epc stats get <jugador> <kit\|global> <campo>` | Lee un contador |
| `/epc stats set <jugador> <kit\|global> <campo> <valor>` | Lo fija |
| `/epc stats add <jugador> <kit\|global> <campo> <cantidad>` | Le suma |
| `/epc stats remove <jugador> <kit\|global> <campo> <cantidad>` | Le resta |
| `/epc stats summary <jugador> <kit\|global>` | Un resumen con formato |
| `/epc kits clear <jugador> [kit\|all]` | Borra los loadouts guardados de ese jugador. Sin kit, los borra todos. |

Campos: `kills`, `deaths`, `wins`, `losses`, `elo`, `best-streak`, `current-streak`, `damage`, `time`.

### Transferencia de datos

| Comando | Qué hace |
|---|---|
| `/epc export [archivo]` | Vuelca la base de datos. Sin nombre, un archivo con marca de tiempo en la carpeta de volcados. |
| `/epc import <archivo>` | Vuelve a cargar un volcado |
| `/epc migrate <archivo> [--skip-stats]` | Convierte un volcado v2 de ExyliaCommons al esquema de este plugin |

`/epc reload` ejecuta cuatro pasos, y uno que falle se informa por su nombre mientras los demás siguen
corriendo:

| Paso | Vuelve a leer |
|---|---|
| `configs` | `config.yml`, `messages.yml`, `scoreboards.yml`, y el prefijo de los mensajes |
| `ranks` | `ranks.yml` |
| `lobby-items` | `items/lobby.yml`, `items/party.yml`, `items/queue.yml` |
| `menus` | Los 61 archivos de menú |

El paso `menus` corre también con `/exylialib reload`, porque un menú compilado guarda los objetos ya
parseados y un cambio de paleta dejaría todas las pantallas con los colores viejos.

<Callout type="note" title="Qué no vuelve a leer una recarga">
Las arenas, los kits y las categorías viven en la base de datos, no en un archivo, y ya están en vivo.
`duel.request-expiry-seconds` se fija en una caché al arrancar y necesita reinicio. Todo lo demás de
`config.yml` se lee fresco en cada acceso, así que con la recarga basta.
</Callout>

## Lista blanca de comandos

Mientras un jugador está **en partida**, **en cola** o **dentro de una zona PvP**, solo se permiten los
comandos listados en `command-whitelist.commands`. Cualquier otro se cancela con un mensaje.

La lista que viene de serie es:

```
msg  message  tell  w  whisper
reply  r  respond
leave  lq  leavequeue
epc  exyliapracticecore  kitsave
```

Un comando encaja por su propio nombre o por su forma `plugin:comando`.
`exyliapractice.bypass.command-whitelist` se salta la comprobación, y `command-whitelist.enabled:
false` apaga todo el sistema.
