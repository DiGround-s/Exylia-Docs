## Admin commands

Everything below needs `exyliapractice.admin`.

| Command | What it does |
|---|---|
| `/exyliapracticecore`, `/epc` | Open the admin menu |
| `/epc reload` | Reload this plugin's configs, ranks, lobby items and menus |

### ELO boosts

| Command | What it does |
|---|---|
| `/epc boost add <player> <multiplier> <duration>` | Grant a personal boost |
| `/epc boost remove <player>` | Cancel it |
| `/epc boost info <player>` | Show it |
| `/epc boost global add <multiplier> <duration>` | Grant a server-wide boost |
| `/epc boost global remove` | Cancel it |
| `/epc boost global info` | Show it |

Durations are `1d`, `12h`, `30m`, `90s`, or combinations like `1d12h`. The multiplier must be above 1.

### Statistics

| Command | What it does |
|---|---|
| `/epc stats get <player> <kit\|global> <field>` | Read a counter |
| `/epc stats set <player> <kit\|global> <field> <value>` | Set it |
| `/epc stats add <player> <kit\|global> <field> <amount>` | Add to it |
| `/epc stats remove <player> <kit\|global> <field> <amount>` | Subtract from it |
| `/epc stats summary <player> <kit\|global>` | A formatted overview |
| `/epc kits clear <player> [kit\|all]` | Delete that player's saved loadouts. Omitting the kit clears all of them. |

Fields: `kills`, `deaths`, `wins`, `losses`, `elo`, `best-streak`, `current-streak`, `damage`, `time`.

### Data transfer

| Command | What it does |
|---|---|
| `/epc export [filename]` | Dump the database. With no name, a timestamped file in the dumps folder. |
| `/epc import <filename>` | Load a dump back in |
| `/epc migrate <filename> [--skip-stats]` | Convert a legacy ExyliaCommons v2 dump into this plugin's schema |

`/epc reload` runs four steps, and one that fails is reported by name while the rest still run:

| Step | Re-reads |
|---|---|
| `configs` | `config.yml`, `messages.yml`, `scoreboards.yml`, and the message prefix |
| `ranks` | `ranks.yml` |
| `lobby-items` | `items/lobby.yml`, `items/party.yml`, `items/queue.yml` |
| `menus` | Every one of the 61 menu files |

The `menus` step also runs on `/exylialib reload`, because a compiled menu holds parsed items and a
palette change would otherwise leave every screen on the old colours.

<Callout type="note" title="What a reload does not re-read">
Arenas, kits and categories live in the database, not in a file, and are already live. `duel.request-expiry-seconds`
is baked into a cache at startup and needs a restart. Everything else in `config.yml` is read fresh on
every access, so a reload is enough.
</Callout>

## Command whitelist

While a player is **in a match**, **queued**, or **inside a PvP zone**, only the commands listed in
`command-whitelist.commands` are allowed. Anything else is cancelled with a message.

The shipped list is:

```
msg  message  tell  w  whisper
reply  r  respond
leave  lq  leavequeue
epc  exyliapracticecore  kitsave
```

A command matches by its own name or by a `plugin:command` form of it. `exyliapractice.bypass.command-whitelist`
skips the check, and `command-whitelist.enabled: false` turns the whole thing off.
