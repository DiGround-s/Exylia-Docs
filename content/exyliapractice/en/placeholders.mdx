Every placeholder below is written in full, and clicking one copies it.

## The reader's stats

All of these read the reader's **global** row for the current season.

| Placeholder | Description |
|---|---|
| `%exyliapracticecore_stats_kills%` | Kills |
| `%exyliapracticecore_stats_deaths%` | Deaths |
| `%exyliapracticecore_stats_kdr%` | Kill/death ratio, one decimal |
| `%exyliapracticecore_stats_wins%` | Wins |
| `%exyliapracticecore_stats_losses%` | Losses |
| `%exyliapracticecore_stats_win_rate%` | Win rate as a percentage |
| `%exyliapracticecore_stats_games%` | Wins plus losses |
| `%exyliapracticecore_stats_current_streak%` | Current win streak |
| `%exyliapracticecore_stats_best_streak%` | Best win streak |
| `%exyliapracticecore_stats_damage%` | Damage dealt, one decimal |
| `%exyliapracticecore_stats_time%` | Time played, formatted |

## Rank

| Placeholder | Description |
|---|---|
| `%exyliapracticecore_stats_elo%` | Raw MMR |
| `%exyliapracticecore_stats_rank%` | The rank name, with its division: `Copper II` |
| `%exyliapracticecore_stats_rank_icon%` | The division's icon, plus the division name |
| `%exyliapracticecore_stats_rank_full%` | `Copper II — 40/100 LP`. Without divisions, `Legend — 240 LP` |
| `%exyliapracticecore_stats_lp%` | LP inside the current division |
| `%exyliapracticecore_stats_lp_max%` | The division's width in LP. `0` for a rank without divisions. |
| `%exyliapracticecore_stats_rank_position%` | The reader's place on the global rating ladder, as `#4` |

`%exyliapracticecore_stats_rank_position%` reads the leaderboard cache and never waits on the database. It answers `-`
while the board is loading, and `#51+` — one past `leaderboard.max-entries` — for anybody outside the
board.

## Leaderboards

```
%exyliapracticecore_stats_top_<stat>_<position>%
%exyliapracticecore_stats_top_<stat>_<position>_value%
```

The first gives the player's name at that position, the second gives the counter itself, formatted.
Positions run from **1 to 10**; anything else answers nothing.

Valid stats:

```
kills  deaths  kdr  wins  losses  win_rate
best_streak  current_streak  damage  time  rank
```

Examples:

```
%exyliapracticecore_stats_top_kills_1%              → the top killer's name
%exyliapracticecore_stats_top_kills_1_value%        → their kill count
%exyliapracticecore_stats_top_win_rate_3_value%     → third place's win rate
%exyliapracticecore_stats_top_rank_1_value%         → the top player's rank and LP
```

These read the **global** leaderboard. A board that has not been loaded yet answers `-` and warms
itself in the background, so a hologram fills in on its second render rather than stalling the first.

## Match

| Placeholder | Description |
|---|---|
| `%exyliapracticecore_game_team_color%` | The reader's side: `&c` for team A, `&9` for team B, empty otherwise |
| `%exyliapracticecore_game_opponent_color%` | The other side's colour |

Both answer empty when the reader is not in a match.

## Server counts

| Placeholder | Description |
|---|---|
| `%exyliapracticecore_total_game_players%` | How many players are in a match right now |
| `%exyliapracticecore_total_queue_players%` | How many are queued |

## Placeholders from other plugins

Sidebars and menus in this plugin resolve the whole server's placeholders, not just its own. The
shipped lobby sidebar uses `%exyliaffa_total_players%` and `%exyliasandbox_total_players%` — remove
those lines if you do not run those plugins, or they render as raw text.
