`config.yml` is version 2 and carries eighteen sections. Every one is generated on first boot with the
defaults below.

Every value here is read fresh on each access, so `/epc reload` is enough to apply an edit — with the
one exception noted under `duel` below.

## `arena`

| Key | Default | What it does |
|---|---|---|
| `max-clones-per-arena` | `10` | Hard ceiling of simultaneous copies of one arena |
| `clone-spacing` | `1500` | Blocks of empty space between clones |
| `clone-paste-y` | `64` | The Y a clone's copy region is pasted at |

## `pvp-regions`

| Key | What it does |
|---|---|
| `combat-tag-bossbar` | The boss bar shown while combat-tagged in a PvP zone. `%time%` is the seconds left. |

| Key | Default | What it does |
|---|---|---|

## `duel`

| Key | Default | What it does |
|---|---|---|
| `request-expiry-seconds` | `30` | How long a challenge stays open |
| `round-end-delay-ticks` | `80` | The pause between rounds |
| `round-won-title` / `round-lost-title` / `round-draw-title` | | With `%my_wins%` and `%their_wins%` |

<Callout type="note" title="request-expiry-seconds is read once">
The expiry is baked into a cache when the plugin enables. It is the one key in this file that a
`/epc reload` cannot pick up — changing it needs a restart.
</Callout>

## `command-whitelist`

| Key | Default | What it does |
|---|---|---|
| `enabled` | `true` | Restrict commands in a match, in a queue and in a PvP zone |
| `commands` | see below | The allowed list |

```yaml
           leave, lq, leavequeue, epc, exyliapracticecore, kitsave, leave]
```

## `web-api`

| Key | Default | What it does |
|---|---|---|
| `enabled` | `false` | Turn the whole integration on |
| `key` | `""` | Your server key. Blank keeps it off even when `enabled` is true. |
| `sync-on-startup` | `true` | Push ranks and kits shortly after boot |
| `player-count-interval-seconds` | `300` | How often the online count is reported |

See [the web API page](/docs/exyliapractice/web-api).

## Migration from ExyliaCommons

A `config.yml` with no `config-version` is treated as version 1 — the ExyliaCommons layout — and
migrated in place. Every title, action bar and boss bar block is moved into the nested section the
library expects, title durations are converted from ticks to seconds, and the obsolete
`%time_decimal%` token is rewritten to `%time%`.

The six sections ExyliaCommons registered against this same file — `debug`, `formatters`, `text`,
`tasks`, `chat-input`, `discord` — were the library's own settings and are removed on first load, each
reported once as `UNKNOWN_KEY`. They live in ExyliaLib's files now.
