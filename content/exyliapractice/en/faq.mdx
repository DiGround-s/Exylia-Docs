## Setup

### `/queue` says there are no arenas available

The kit's **compatible arenas** list is empty, or every arena in it is disabled or not fully
configured. Open the kit, check the list, then open each arena and look at **Status** — it names what
is missing.

### An arena refuses to enable and says a schematic is missing

Either you have not pressed **Schematic** yet, or FastAsyncWorldEdit is not installed. The check asks
the schematic store whether the file exists, and a server without FAWE always answers no. The real
reason was logged once at startup.

### Nothing teleports to the lobby

The lobby spawn is not set. `/epc` → **Data Management** → **Set Lobby**.

### The kit editor drops players wherever they were standing

The kit editor spawn is not set. Same menu, **Set Kit Editor Spawn**.

### My two test accounts never get matched

Same-IP protection. Set `elo-security.same-ip-protection` to `false` while you are testing, or use
`/duel` which does not check it.

## Running it

### I edited a config and nothing changed

Run `/epc reload`. It re-reads the three config files, `ranks.yml`, the three `items/` files and every
menu. Two things it cannot pick up: arenas and kits, which live in the database and are already live,
and `duel.request-expiry-seconds`, which is baked into a cache at startup and needs a restart.

If a step fails, the reload names it and still runs the rest — read what it printed rather than
restarting blind.

### The admin menu files say they are regenerated on every startup

Only on installs from an older build. That banner was never true — the plugin skips any menu file that
already exists — and it has been removed from the shipped copies. Yours keeps it precisely because
nothing overwrites your files. Delete those five lines and edit normally.

### Ender pearls have a huge cooldown

`ender-pearl-cooldown` is in **seconds**, so `16` is sixteen seconds. `1` is closest to vanilla. Older
builds labelled it `ticks` in the rules menu, which is where the confusion came from; the stored value
was always seconds.

### The clone world was created in my lobby world

You are on Folia without the Worlds plugin. Folia cannot create a world through Bukkit, so the plugin
falls back to the main world — which means arena clones are pasted into it. Install
[Worlds](https://repo.thenextlvl.net) and restart.

### Clones are eating the server

Lower `arena.max-clones-per-arena`. Each clone is a permanent paste in the clone world that stays
loaded for the life of the server, and ten of a large arena is a lot of chunks. Clones are only made
when every existing instance is busy, so a lower limit means matches queue instead.

## Gameplay

### Blocks are not being restored between matches

Regeneration only runs when the kit allows `build` or `block-break` — there is nothing to restore
otherwise. If the kit does allow building and blocks still persist, re-save the arena's schematics: a
regeneration restores the file, not what is standing.

### A player's points went negative

A `LOSS_POINT` special condition subtracts without a floor. It costs them nothing beyond the display —
a winner is only ever resolved from a positive score — but pair `LOSS_POINT` with something that ends
the round if you want it to be decisive.

### Nobody can spectate a match

One of the players in it has **spectators** turned off in `/settings`. It is one player's veto over
the whole match. If nobody has it off, check the arena has a **spectator spawn** — without one the
teleport fails and spectating cannot start.

### Hits-to-win seems backwards

It counts hits **received**, not dealt. `hits-to-win: 100` eliminates a player once they have taken a
hundred hits. That is the standard boxing rule.

### A player has more loadout slots than I gave them

`exyliapractice.kits.max_slots.<n>` counts down to the highest node the player holds, and everybody
gets **one** slot with no node at all. Check for a wildcard or an inherited group.

## Stats and ELO

### A season rotation deleted everybody's stats

It did not. The old rows are still in `practice_player_season_stats` under the previous season number,
and the lifetime tier was never touched. What resets is what the leaderboards read.

### A high-rated player barely loses LP

That is the asymmetric reduction. Once the rating gap is above `elo.asymmetric-threshold-mmr`, the
higher-rated player's loss shrinks, and by a gap of about 700 it reaches zero. Turn it off by setting
`asymmetric-threshold-mmr` very high.

### `/epc stats set` did not change the leaderboard

Leaderboards are cached for five minutes. Wait, or restart.

### Two players are farming each other with duels

The anti-boost checks only run at matchmaking time. Turn **ranked** off on the kits you offer for
duelling, or **duel** off on the ranked ones.

## Integration

### `/linkpractice` always says network error

Check `web-api.enabled` and that `key` is not blank — both are needed. If the integration is on and it
still fails on every code, note that the plugin classifies the API's reply by looking for Spanish words
in it; an API answering in another language degrades every failure to a generic network error.

### Matches are not reaching the website

They are queued in `practice_web_outbox` and retried every five seconds with backoff. Check the console
for `[WebApi]` warnings. Nothing is lost while the web is down; a row is only dropped after twelve
outright rejections.
