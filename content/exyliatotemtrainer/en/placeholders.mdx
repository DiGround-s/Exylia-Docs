Every placeholder below is written in full, and clicking one copies it.

## How the name is written

Everywhere outside the plugin — PlaceholderAPI, and anything reading through it — a placeholder is the
plugin name, the group `totem`, and the placeholder's own name:

```text
%exyliatotemtrainer_totem_wins%
```

That is the only identifier this plugin answers to. Inside its own files — `scoreboards.yml`, `menus/`,
`messages.yml` — the same placeholder is written with the group and nothing in front of it, because the
plugin resolves its own text without going through PlaceholderAPI:

```text
%totem_wins%
```

<Callout type="danger" title="The word totem is part of the name">
`%exyliatotemtrainer_wins%` does **not** resolve. PlaceholderAPI hands the plugin `wins`, the plugin
registered `totem_wins`, and nothing matches. Every PlaceholderAPI form of these placeholders reads
`%exyliatotemtrainer_totem_<name>%`.
</Callout>

Every placeholder resolves for the player looking at it. One that has no value — no viewer, no profile
loaded yet, no running session — leaves the text unchanged rather than writing an empty string.

## Duel record

| Placeholder | Description |
|---|---|
| `%exyliatotemtrainer_totem_wins%` | Duels won. |
| `%exyliatotemtrainer_totem_losses%` | Duels lost. |
| `%exyliatotemtrainer_totem_winrate%` | Wins over duels played, as a percentage: `50%`. |
| `%exyliatotemtrainer_totem_best_streak%` | Best run of duel wins in a row. |

## Pops

| Placeholder | Description |
|---|---|
| `%exyliatotemtrainer_totem_total_pops%` | Lifetime pops, training and duels together. |
| `%exyliatotemtrainer_totem_pops%` | Pops of the running session; lifetime pops outside one. |
| `%exyliatotemtrainer_totem_streak%` | Pops in a row of the running session; the current duel win streak outside one. |
| `%exyliatotemtrainer_totem_best%` | Fastest reaction of the running session, or the lifetime best: `0.72s`. `—` when none. |
| `%exyliatotemtrainer_totem_average%` | Average reaction of the running session, or the lifetime average: `0.72s`. `—` when none. |

These four are the ones a sidebar line and a lobby lore can share: the same name means the live session
while one is running and the lifetime profile otherwise.

## The running session

Training and duels both count as a session here.

| Placeholder | Description |
|---|---|
| `%exyliatotemtrainer_totem_state%` | `none`, `training` or `match`. |
| `%exyliatotemtrainer_totem_state_label%` | The same, in the words of `menu.state-none`, `state-training` and `state-match`: `None`, `Training`, `Duel`. |
| `%exyliatotemtrainer_totem_mode%` | The display name of the mode being played. |
| `%exyliatotemtrainer_totem_ticks%` | The interval the player picked, in ticks. |
| `%exyliatotemtrainer_totem_interval%` | The interval the session is running at right now, which an accelerating mode keeps moving. Falls back to `ticks`. |
| `%exyliatotemtrainer_totem_grade%` | The grade of the last pop: `Perfect`, `Excellent`, `Good`, `Ok` or `Slow`. `—` before the first pop; nothing outside a session. |
| `%exyliatotemtrainer_totem_session_time%` | How long the session has been running. |

## The running duel

| Placeholder | Description |
|---|---|
| `%exyliatotemtrainer_totem_format%` | The series length: `BO3`. |
| `%exyliatotemtrainer_totem_opponent%` | The opponent's name. |
| `%exyliatotemtrainer_totem_opponent_pops%` | The opponent's pops in the current round. |
| `%exyliatotemtrainer_totem_round%` | The round being played. A replayed draw keeps its number. |
| `%exyliatotemtrainer_totem_score%` | Rounds won, yours first: `2 - 1`. |
| `%exyliatotemtrainer_totem_match_state%` | `waiting`, `starting`, `active`, `round_end`, `ending` or `finished`. |

## Leaderboards

A board is about one mode and sorted by one category, and both go in the name. Every board placeholder
comes in two forms: the plain one answers the player standing at position `n`, and the one ending in
`_value` the number that put them there.

`<mode>` is a mode id from `config.yml` — `normal`, `infinite`, `random`, `chaos`, `acceleration` and
`blackout` in the file the plugin ships — and `<n>` is the position, counting from 1.

| Placeholder | Sorted by | What it answers |
|---|---|---|
| `%exyliatotemtrainer_totem_top_<mode>_rating_<n>%` | Best session score weighted by the speed it was set at, highest first | The name of the player at that position. |
| `%exyliatotemtrainer_totem_top_<mode>_rating_<n>_value%` | The same board | Their rating: `87`. |
| `%exyliatotemtrainer_totem_top_<mode>_best_pops_<n>%` | Most pops in one session, highest first | The name of the player at that position. |
| `%exyliatotemtrainer_totem_top_<mode>_best_pops_<n>_value%` | The same board | Their pops: `112`. |
| `%exyliatotemtrainer_totem_top_<mode>_fastest_average_<n>%` | Best average reaction, lowest first | The name of the player at that position. |
| `%exyliatotemtrainer_totem_top_<mode>_fastest_average_<n>_value%` | The same board | Their average: `0.41s`. |
| `%exyliatotemtrainer_totem_top_<mode>_best_streak_<n>%` | Longest run of pops without a fail, highest first | The name of the player at that position. |
| `%exyliatotemtrainer_totem_top_<mode>_best_streak_<n>_value%` | The same board | Their streak: `64`. |
| `%exyliatotemtrainer_totem_top_<mode>_longest_run_<n>%` | Longest session, highest first | The name of the player at that position. |
| `%exyliatotemtrainer_totem_top_<mode>_longest_run_<n>_value%` | The same board | How long it lasted: `95.30s`. |

Written out, with a mode and a position in place:

```text
%exyliatotemtrainer_totem_top_chaos_rating_1%
%exyliatotemtrainer_totem_top_chaos_rating_1_value%
%exyliatotemtrainer_totem_top_acceleration_fastest_average_3%
%exyliatotemtrainer_totem_top_acceleration_fastest_average_3_value%
```

A mode id or a category with underscores in it is matched whole:
`%exyliatotemtrainer_totem_top_my_mode_best_pops_1%` finds the mode `my_mode`. Until the board has been
read once, both forms answer the `menu.loading` text, `Loading…`, and kick the read off. A position past
the end of the board, an unknown mode or an unknown category leaves the text unchanged. See
[Stats](/docs/exyliatotemtrainer/stats) for how a board is built.
