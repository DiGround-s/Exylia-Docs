## Installing

<Steps>
  <Step title="Drop the jars in">
    `ExyliaArmorTrims.jar` and `packetevents` in `plugins/`. `ExyliaLib` is a soft depend: if it is
    missing, the loader installs it on the first start.
  </Step>
  <Step title="Start the server">
    It writes `config.yml`, `trims.yml` and `menus/trims.yml`.
  </Step>
  <Step title="Pick the mode">
    `behaviour.mode` in `config.yml`: `item`, `menu` or `both`. See
    [Modes and items](/docs/exyliaarmortrims/modes-and-items).
  </Step>
  <Step title="Grant the permissions">
    With no nodes granted the menu opens locked. See
    [Permissions](/docs/exyliaarmortrims/permissions).
  </Step>
</Steps>

## Files

| File | Contents |
|---|---|
| `config.yml` | Mode, items, armor lore, effects, menu wording and messages. |
| `trims.yml` | The patterns and materials on offer, and the named presets. |
| `menus/trims.yml` | The one trim screen. |
| `database.yml` | Only when the mode uses the menu. H2 by default. |

## The database

With `mode: item` **none is opened**: a server running on trim items alone stores nothing per player,
and never finds a `database.yml` it did not ask for. An `/armortrimsadmin reload` that turns the menu
on opens it then.

With `menu` or `both`, choices live in the `armortrim_selection` table, one row per player and one
column per piece:

| Column | What it holds |
|---|---|
| `uuid` | The player. |
| `helmet`, `chestplate`, `leggings`, `boots` | A preset id — `shogun` — or a `pattern/material` pair — `sentry/netherite`. |

Four columns rather than a JSON blob on purpose: they can be read, queried and exported.

<Callout type="note" title="A slot may hold something that no longer exists">
A value the registry does not know — a preset deleted from `trims.yml`, a material you removed — is
not drawn and is **not cleaned up**. It comes back the day the entry does, which is what a typo in a
reload deserves.
</Callout>

## Updating

Replace the jar and restart. `/armortrimsadmin reload` re-reads `config.yml`, `trims.yml` and the
menu, and redraws everybody online.
