---
title: "The menu"
description: "One screen: the tabs, the grid, the favourites, and every template menus/effects.yml declares."
---

`/killeffect` opens one window of 54 slots. Nothing in it touches a weapon — an effect gets onto a
weapon through its token, which is the thing a server sells.

<Callout type="note" title="It refuses to open in weapon mode">
With `behaviour.mode: weapon` nothing on this screen would ever be read, so the menu answers
`menu-disabled` instead of opening a window that changes nothing.
</Callout>

## The two lists

| Section | Slots | What it holds |
|---|---|---|
| `categories` | `9,18,27,36` | The tabs down the left, paged with the buttons at slots `0` and `45`. |
| `grid` | `11-16,20-25,29-34,38-43` | The open category's effects, paged at slots `47` and `52`. |

The fixed buttons: **YOUR EFFECT** at slot `4` (click to take the effect off), **EFFECT CRATE** at
`8`, **PARTICLE VISIBILITY** at `48`, **RANDOM EFFECT** at `49`, **CLOSE** at `50`.

## The favourites tab

The first tab is always the player's own shortlist — it is not a category in `effects.yml`, because it
holds different effects for every player. It is named and drawn by `menu.favourites-name` and
`menu.favourites-icon` in `config.yml`.

| Rule | Detail |
|---|---|
| Starring is free | Owning an effect is not required to star it. A star that vanished the day a rank lapsed would lose them the list they built. |
| Their order, not yours | Starred effects stay in the order they were starred. Nothing is re-sorted. |
| Locked rows still show | On this tab a locked effect is drawn even on a server that hides locked effects everywhere else. |
| Emptying it | Shift click the tab while it is open, or `/killeffect favourites clear`. |

An empty shortlist draws `empty_template` so the tab reads as empty rather than as a screen that
failed to load.

## What a click does

| Click | On a grid row |
|---|---|
| Left | Wears the effect — or takes it off, when it is already the one worn. |
| Right | Previews it on the server's preview stage, set with `/killeffectsadmin preview location`. Locked rows can be previewed too. |
| Shift | Stars it, or unstars it. |

## Ordering and locked rows

Effects the player may use are drawn first, then the locked ones — so what they can use is never
behind a page of rows they cannot. With `behaviour.hide-without-permission: true` the locked ones are
dropped from the grid entirely, except on the favourites tab.

## The random choice

**RANDOM EFFECT** at slot `49` is a choice rather than an effect: every kill draws a different one of
the effects the player owns. It is turned on and off by clicking it, by `/killeffect random`, or by
the `killeffect:random` action, and what it is called is `menu.random-name`.

## The crate

**EFFECT CRATE** at slot `8` opens `menus/crate.yml`, which asks how many to open and hands over to
`menus/crate_open.yml` for the reels. Both are documented on [The crate](/docs/exyliakilleffect/crate).

## Templates

Each list picks a template per row. `item_template` is the plain state and must stay first.

| Section | Template | Used when |
|---|---|---|
| `categories` | `item_template` | Another tab is open. |
| | `open_template` | This is the tab being looked at. |
| | `favourites_template` | The shortlist tab, while another tab is open. |
| | `favourites_open_template` | The shortlist tab while it is open — the only one carrying the "empty the list" action. |
| `grid` | `item_template` | An effect the player owns. |
| | `selected_template` | The effect currently worn. |
| | `locked_template` | An effect they do not own. |
| | `empty_template` | Drawn on the favourites tab when nothing is starred. |

## Placeholders

These are the menu's own tokens, filled in while the screen is drawn. They are not PlaceholderAPI
placeholders and only work inside this file.

| Placeholder | Where | What it draws |
|---|---|---|
| `%category_id%` | `categories` | The tab's id — `favourites` on the shortlist tab. |
| `%category_name%` | `categories` | The tab's display name. |
| `%category_material%` | `categories` | The material its icon is drawn with. |
| `%category_total%` | `categories` | How many effects the tab holds. |
| `%category_owned%` | `categories` | How many of those the player owns. |
| `%category_status%` | `categories` | `menu.tab-open` or `menu.tab-closed`, depending on whether this is the tab being looked at. |
| `%effect_id%` | `grid` | The effect's id. |
| `%effect_name%` | `grid` | Its display name, with its colours. |
| `%effect_material%` | `grid` | The material it is drawn with. |
| `%effect_description%` | `grid` | Its description from `effects.yml`. |
| `%effect_weapons%` | `grid` | What it may be bound to, in words. |
| `%effect_favourite%` | `grid` | `menu.favourite-on` or `menu.favourite-off`, depending on whether it is starred. |
| `%effect_tier%` | `grid` | The rarity's name, in the rarity's colour. |
| `%effect_tier_id%` | `grid` | The rarity's id. |
| `%effect_tier_color%` | `grid` | That colour on its own. |
| `%current_effect%` | Anywhere | The effect the player is wearing, `menu.random-name` on random, or `menu.empty`. |
| `%random_status%` | Anywhere | `menu.random-on` or `menu.random-off`. |
| `%favourites_count%` | Anywhere | How many effects they have starred. |
| `%keys%` | Anywhere | Crate keys they hold. |
| `%unlocked_count%` | Anywhere | How many effects they have won from the crate. |
| `%catalogue_count%` | Anywhere | How many effects the server declares. |
| `%particle_visibility%` | Anywhere | The player's current visibility mode, named as `particles.name-*` says. |
| `%visibility_all%` | Anywhere | The name of the "everyone" mode, for a button that offers it. |
| `%visibility_none%` | Anywhere | The name of the "nobody" mode. |
| `%visibility_self_only%` | Anywhere | The name of the "only me" mode. |
| `%visibility_others_only%` | Anywhere | The name of the "only others" mode. |

## Actions

| Action | What it does |
|---|---|
| `killeffect:open` | Opens the screen. |
| `killeffect:category <id>` | Switches tab. `favourites` is a valid id. |
| `killeffect:choose <id>` | Wears an effect, or takes it off when it is already worn. |
| `killeffect:clear` | Takes the effect off. |
| `killeffect:favourite <id>` | Stars or unstars. |
| `killeffect:favourites_clear` | Empties the shortlist. |
| `killeffect:preview <id>` | Previews an effect and reopens the menu afterwards. |
| `killeffect:visibility` | Steps the viewer's visibility on by one. |
| `killeffect:random` | Turns the random choice on, or off when it is already on. |
| `killeffect:crate` | Opens the crate. |
| `killeffect:crate_open <amount>` | Spends that many keys and drops that many reels. Used by `menus/crate.yml`. |

## Wording

The few strings one template draws for every row live in `config.yml`, because no file can spell them
out row by row:

```yaml title="config.yml"
menu:
  empty: "{muted}Nothing"
  tab-open: "{success}✔ You are here"
  tab-closed: "{warning}➥ Click to open"
  weapons-any: "Any weapon"
  favourites-name: "Favourites"
  favourites-icon: "AMETHYST_SHARD"
  favourite-on: "{highlight}★ In your favourites"
  favourite-off: "{muted}☆ Not in your favourites"
  random-name: "{highlight}Random"
  random-on: "{success}✔ Every kill is a surprise"
  random-off: "{warning}➥ Click to surprise yourself"
```

<Callout type="tip" title="The window follows the choice">
Every way a player's row can change — their own click, a command, an admin, or a rank that ran out
under them — redraws whatever windows they have open. Nothing has to be closed and reopened.
</Callout>
