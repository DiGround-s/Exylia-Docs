## The menu path

<Steps>
  <Step title="Let players open the menu">
    ```text
    /lp group default permission set exyliakilleffect.command.killeffect true
    ```
    Without this the catalogue cannot be opened at all — and a player who cannot see it cannot want
    anything in it.
  </Step>
  <Step title="Sell a category">
    ```text
    /lp group vip permission set exyliakilleffect.category.siege true
    ```
    Twenty effects, one node.
  </Step>
  <Step title="Open it">
    `/killeffect`. The tabs are down the left, the effects beside them, and the first tab is the
    player's own favourites.
  </Step>
  <Step title="Pick one and kill something">
    Left click wears it. The effect plays where the victim falls — as long as the victim's type is
    allowed.
  </Step>
</Steps>

<Callout type="warning" title="Only three victims count by default">
`effects.all-mobs` is `false` and `effects.allowed-mobs` lists `PLAYER`, `MANNEQUIN` and `ZOMBIE`.
A test kill on a cow plays nothing, and that is the setting, not a bug.
</Callout>

## The crate path

<Steps>
  <Step title="Put the crate somewhere">
    ```text
    /killeffectsadmin crate block add
    ```
    Binds the block you are looking at, so clicking it opens the crate. The button in the corner of
    the menu and `/killeffect crate` open the same screen.
  </Step>
  <Step title="Hand over a key">
    ```text
    /killeffectsadmin keys give <player> 1
    ```
    That key lives on the player's row, which is what a shop, a vote listener or a reward plugin
    runs as console. For one they can hold, sell and give away instead, `item key <player> 1`.
  </Step>
  <Step title="Open it">
    One key, one reel. A key in the hand opens it with a right click on the block; a key on the row
    opens it from the screen. What comes out is theirs for good — see
    [The crate](/docs/exyliakilleffect/crate).
  </Step>
</Steps>

## The weapon path

<Steps>
  <Step title="Give a token">
    ```text
    /killeffectsadmin item give <player> blade_storm 1
    ```
  </Step>
  <Step title="Drop it onto a weapon">
    Pick the token up with the cursor and click it onto a weapon **in your own inventory**. The
    weapon keeps everything it had; one value is written onto it.
  </Step>
  <Step title="Take it off again">
    ```text
    /killeffectsadmin item remover <player>
    ```
    The remover unbinds the effect and hands the token back, so nothing is destroyed.
  </Step>
</Steps>

## Checking it works

| Question | How to answer it |
|---|---|
| Is the effect there? | `/killeffect preview <id>` — it plays on the preview stage. Set one first with `/killeffectsadmin preview location`. |
| Does the weapon carry one? | Its line is drawn under the weapon's own lore. |
| Did a permission take? | `/killeffectsadmin player validate <player>` takes off what they may no longer use, now. |
| Did the file load? | `/killeffectsadmin list` prints every effect the catalogue declares. |
