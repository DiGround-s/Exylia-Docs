Un efecto es una lista de **pasos**, en orden. Cada paso es un token entre corchetes, con qué se
dibuja, y parámetros separados por `;`:

```yaml
- '[CIRCLE] NETHERITE_SWORD;as:item;radius:3;points:12;from:0,10,0;ease:in'
```

`(0,0,0)` es donde cayó la víctima. La Y positiva es arriba.

## Displays o partículas

Una línea de forma dibuja **displays** cuando lleva `as:`, y partículas cuando no.

| Escrito | Se dibuja con |
|---|---|
| `as:item` | El modelo de un objeto. |
| `as:block` | El modelo de un bloque. |
| `as:head` | Una cabeza: una textura en base64, o `{killer}` / `{victim}` para una cara. |
| `as:text` | Una línea de texto. |
| *(nada)* | La partícula nombrada al principio de la línea. |

```yaml
- '[CIRCLE] FLAME;radius:2.0;points:32;color:255,80,0'      # partículas
- '[CIRCLE] DEEPSLATE;as:block;radius:3.4;points:12'         # displays
```

## Formas

Veinticinco, más `DISPLAY` para un solo objeto en el ancla y `PIXELS` para un dibujo o una palabra:

`CIRCLE` `SPHERE` `DOME` `CUBE` `LINE` `RIBBON` `SCATTER` `BEAM` `SPIRAL` `DOUBLE_HELIX` `TORNADO`
`STAR` `CAGE` `DISC` `VORTEX` `WAVE` `CROSS` `GALAXY` `TORUS` `BURST` `PYRAMID` `RING_PULSE` `WINGS`
`ARCH` `CLAW` `DISPLAY` `PIXELS`

Cada una tiene sus parámetros:

| Forma | Parámetros |
|---|---|
| `CIRCLE`, `SPHERE`, `DOME` | `radius` `points` |
| `BEAM` | `height` `points` |
| `SPIRAL` | `height` `radius` `turns` `points` |
| `DOUBLE_HELIX` | `height` `radius` `turns` `points` `strands` |
| `TORNADO` | `height` `radius` `top_radius` `turns` `points` |
| `STAR` | `radius` `spikes` `inner` `points` |
| `CAGE` | `radius` `height` `columns` `points` |
| `DISC` | `radius` `rings` `points` |
| `VORTEX` | `radius` `turns` `points` |
| `WAVE` | `length` `amplitude` `frequency` `arms` `angle` `points` |
| `CROSS` | `radius` `arms` `angle` `points` |
| `GALAXY` | `radius` `turns` `arms` `points` |
| `TORUS` | `radius` `tube` `segments` `tube_segments` |
| `BURST` | `radius` `beams` `angle` `points` |
| `PYRAMID` | `base` `height` `points` |
| `RING_PULSE` | `radius` `rings` `spacing` `points` |
| `WINGS` | `span` `arch` `depth` `dir` `points` |
| `ARCH` | `radius` `arc` `dir` `points` |
| `CLAW` | `radius` `claws` `spread` `curve` `dir` `drop` `points` |
| `CUBE` | `width` `points` `edges` |
| `LINE` | `length` `dir` `climb` `points` |
| `RIBBON` | `radius` `points` `waves` `amplitude` |
| `SCATTER` | `radius` `height` `points` `seed` `floor` |
| `DISPLAY` | *(ninguno — un objeto en el ancla)* |
| `PIXELS` | `art` o `word`, `pixel` `pick` `depth` — abajo |

### Lo que entiende cualquier forma

`y` `scale` `color` `size` `count` `ticks` `interval` `face` `rotate`

| Parámetro | Qué hace |
|---|---|
| `y` | Sube la forma entera. `SPHERE` y `TORUS` van un bloque arriba por defecto; el resto, a cero. |
| `scale` | Agranda o encoge la geometría. |
| `ticks` | `1` dibuja toda la forma en un frame; más la reparte en el tiempo, que es lo que hace que una espiral parezca trazarse. |
| `interval` | Segundos entre esos frames. Por defecto `0.05`. |
| `rotate` | Gira la forma entera, en grados. |
| `face` | La orienta hacia quien causó la baja. |
| `color`, `size`, `count` | Solo en líneas de partículas: `DUST` acepta `color:255,80,0`, `size` es el punto y `count` las partículas por punto. |

## Mover un display

Todo lo de abajo funciona en cualquier forma dibujada con `as:`.

| Parámetro | Qué hace |
|---|---|
| `life` | Segundos que existe. |
| `from:x,y,z` | Dónde empieza, relativo a su punto. |
| `to:x,y,z` | Dónde termina. `rise:` es el atajo para un `to` vertical. |
| `ease` | `in`, `out` o `in_out`. `ease:in` apunta un golpe hacia abajo. |
| `gravity` | Solo para escombros. Se **suma** al movimiento en lugar de reemplazarlo. |
| `spin` | Vueltas, o `x,y,z` para voltear. `axis` elige un solo eje. |
| `orbit` | Vueltas alrededor del ancla. |
| `pull` | `1` llega al centro; un número negativo lo lanza hacia fuera. |
| `size` | Un número, o `x,y,z` para una placa, un pilar o una hoja. |
| `size_to` | El tamaño con el que acaba. |
| `vary` | Cuánto se diferencian las piezas entre sí. |
| `roll`, `tilt`, `turn` | Rotación fija en grados. |
| `face_out` | Mira hacia fuera del centro. |
| `glow` | Un color de contorno. |
| `light` | De `0` a `15`. Usa `light:15` para lo que deba verse de noche. |
| `model`, `billboard`, `hold` | El modelo del display, su modo billboard y cuánto se sostiene. |

<Callout type="warning" title="Tres reglas que ahorran una tarde">
`ease:in` apunta un impacto y `ease:out` lo asienta. `gravity:` se suma a un movimiento que ya baja,
así que una caída de ocho bloques más gravedad atraviesa el suelo — la mitad de la gravedad por el
cuadrado de `life` es cuánto cae. Y `roll:` apunta una hoja, no `tilt:`: el modelo de un objeto es una
placa plana mirando al sur con la punta arriba y a la derecha, así que `roll:135` la baja.
</Callout>

El escenario se escribe sobre los ejes del mundo: x es el este, z es el sur. Un cuerpo no — mira hacia
quien lo mató — así que el escenario que tenga que cuadrar con él se pone a su alrededor (círculos,
rayos, lo que esté justo encima) o se escribe como texto, que mira a quien lo ve.

## `[PIXELS]` — dibujos y palabras

Un dibujo o una palabra hechos de bloques, celda a celda. `SLAPPED` hace crecer su palabra, y luego la
deja subir y encogerse hasta desaparecer:

```yaml
- '[PIXELS] RED_CONCRETE;as:block;word:SLAP;pixel:0.12;face:true;y:2.7;ease:out;life:0.25;size:0.02;size_to:0.12;light:15'
- '[DELAY] 0.25'
- '[PIXELS] RED_CONCRETE;as:block;word:SLAP;pixel:0.12;face:true;y:2.7;from:0,0,0;to:0,0.4,0;ease:in;life:0.8;size:0.12;size_to:0.02;light:15'
```

| Parámetro | Qué hace |
|---|---|
| `art` | Un dibujo: `heart` `heart_big` `broken_heart` `star` `crown` `skull` `bolt` `note` `cloud` `trophy` `ufo` `moon` `guillotine` `blade` `grave` `portal` `eye` `clock` `rift` `flag`. |
| `word` | Letras en vez de un dibujo. |
| `pixel` | El tamaño de una celda, en bloques. |
| `pick` | Qué caracteres del dibujo pinta esta línea: `#` el cuerpo, `o` el contorno, `w` el brillo, `y` las gemas. Dos líneas con dos materiales colorean un solo dibujo. |
| `depth` | Lo acerca a quien mira. |
| `face:true` | Lo gira hacia quien hizo la baja, que es lo que mantiene una palabra al derecho. |

Todo lo de [Mover un display](#mover-un-display) funciona también aquí.

## Repetir una línea

`repeat` `every` `turn_each` funcionan en **cualquier** paso — un sonido, una forma, un anillo de
espadas:

```yaml
- '[CIRCLE] NETHERITE_SWORD;as:item;radius:2;points:6;repeat:3;every:0.2;turn_each:15'
```

| Parámetro | Qué hace |
|---|---|
| `repeat` | Cuántas veces se lanza la línea. |
| `every` | Segundos entre lanzamientos. Por defecto `0.15`. |
| `turn_each` | Grados que se suman cada vez, para abrir las copias en abanico. |

## Los demás tokens

| Token | Parámetros |
|---|---|
| `[DELAY] 0.15` | Segundos de espera antes de la línea siguiente. |
| `[PARTICLE] FLAME` | `count` `speed` `y` `color` `size` `offset:x,y,z` `block` |
| `[SOUND] NOMBRE;volumen;tono` | También `volume:` `pitch:`. Un volumen por encima de `1.0` se lee como `1.0`: un sonido más fuerte solo llega más lejos, dieciséis bloques por punto. |
| `[LIGHTNING]` | `volume:` `pitch:` — destello, chispas y trueno. Sin rayo real, sin fuego, sin daño. |
| `[EXPLOSION]` | `count:` `y:` |
| `[FIREWORK]` | `color:` `fade:` `type:` `trail:` `flicker:` `power:` |
| `[BLOCK_BREAK] STONE` | `count:` `y:` `offset:` |
| `[POTION] speed;100;1` | También `duration:` `amplifier:` |
| `[TITLE] título;subtítulo;in;stay;out` | Tiempos en segundos. |
| `[ACTION_BAR] texto` | |
| `[MESSAGE] texto` | Una línea de chat. |
| `[COMMAND] give {player} …` | `{player}` `{world}` `{x}` `{y}` `{z}` |
| `[RAGDOLL] {victim}` | El cuerpo en sí, coreografiado, abajo. |
| `[NPC] {victim}` | Un jugador falso entero, abajo. |

## `[RAGDOLL]` — el cuerpo en sí

El cuerpo de la propia víctima con todas sus articulaciones — cabeza, torso, dos brazos, dos piernas,
cada parte con los colores de su propia skin — movido fotograma a fotograma como una escena propia.
Los 100 efectos de fábrica se construyen sobre él.

```yaml
- '[RAGDOLL] {victim};intact:0.1;detail:2;light:15;then:burst;keys:0.25 crouch ease=anticipate | 0.4 stand up=1.6 flip=~-360 ease=out | 0.35 up=0 ease=bounce'
```

### De quién es el cuerpo

La primera palabra dice de quién es:

| Cabecera | Cuerpo |
|---|---|
| `{victim}` | Quien murió. |
| `{killer}` | Una copia de quien hizo la baja, actuando la muerte. |
| `{crowd}` | Con `seat:N`, el enésimo jugador que mira cerca — o un desconocido si no mira nadie. |

Todos los cuerpos miran hacia el lado del asesino, así que `at=0,0,2 turn=180` es alguien a dos
bloques mirando a la víctima.

### `keys` — la coreografía

Los fotogramas se separan con `|`. Cada uno empieza con los segundos que tarda en llegar desde el
anterior — los mismos números que suman las líneas `[DELAY]` del efecto — y luego lista solo lo que
cambia. El cuerpo empieza de pie donde murió, en cuanto acaba `intact`. Un fotograma de `0` segundos
es donde empieza en su lugar, que es como un segundo cuerpo aparece al otro lado desde el primer tick.

| Canal | Qué mueve |
|---|---|
| `at=right,up,forward` | La cadera, en bloques. También `right=` `up=` `forward=` por separado. |
| `flip=` `turn=` `lean=` | El cuerpo entero: hacia delante, hacia su izquierda, hacia su derecha. |
| `head=` `body=` | `pitch,yaw,roll`: asiente hacia delante, gira a la izquierda, se inclina a la derecha. |
| `arm_r=` `arm_l=` `leg_r=` `leg_l=` | `pitch,yaw,roll`: balancea hacia delante y arriba, abre hacia fuera un miembro levantado, lo separa del cuerpo. |
| `arms=` `legs=` | Los dos lados a la vez, en espejo. |
| `<joint>_at=out,up,forward` | Separa una parte de su articulación. |
| `size=` `<joint>_size=` | Cuánto mide el cuerpo, o una de sus partes. |
| `shake=` | Cuánto tiembla, en bloques. |
| `ease=` | `in_out` (por defecto), `in`, `out`, `linear`, `back`, `anticipate`, `elastic`, `bounce`, `snap`, `smooth`. |

Los ángulos van en grados. `~90` suma a donde ya está un canal, así que `turn=~360` es una vuelta
completa más. `smooth` pasa por un fotograma sin detenerse en él, que es lo que necesita un balanceo o
un recorrido.

Una palabra suelta es una pose entera, y lo que la sigue en el fotograma se escribe encima:

`stand` `tpose` `star` `cheer` `reach` `zombie` `hug` `crouch` `sit` `kneel` `lie` `prone` `bow`
`pray` `dab` `superman` `splits` `float` `limp` `fetal` `swoon` `heart` `arabesque`

### Cómo termina

`then:` es lo que pasa después del último fotograma, calculado a partir de cómo se movía cada pieza.

| Valor | Qué pasa |
|---|---|
| `hold` | Se queda como lo dejó el último fotograma. |
| `burst` | Revienta. Lee `speed` `up` `spread` `gravity` `bounce` `spin`. |
| `collapse` | Cae al suelo donde está. |
| `implode` | Se recoge sobre sí mismo. Lee `turns`. |
| `dissolve` | Se deshace hasta desaparecer. |
| `spell` | Cada pieza se coloca formando la palabra de `sign:` — de `letters:` de alto, a `rise:` del suelo — con la cabeza flotando encima, aguanta y cae. |

### Objetos, cuerdas y cadenas

| Parámetro | Qué hace |
|---|---|
| `follow` | Cuánto se retrasan y se pasan las articulaciones sueltas: brazos que se quedan atrás en un salto, una cabeza que cabecea al aterrizar. `1` es un cuerpo, `2` es un dibujo animado. |
| `hold`, `offhand`, `hat` | Un objeto en una mano o en la cabeza, llevado a donde vaya el cuerpo. `hold_size`, `hat_size` y `hat_y` les dan tamaño y altura. |
| `strings` | Cuerdas de marioneta desde las manos y la cabeza, hasta esa altura. |
| `chains` | Encadena las dos muñecas al suelo a esa distancia a cada lado, arrastradas por cada movimiento de los brazos. |
| `snip` | El segundo en que se rompen las cuerdas o las cadenas. |

### El resto

| Parámetro | Qué hace |
|---|---|
| `intact` | Segundos que el cuerpo aguanta entero antes de que empiecen sus fotogramas. |
| `life` | Segundos que dura. Sin él, el cuerpo vive lo que necesiten sus fotogramas y su final. |
| `detail` | Celdas en que se corta cada parte, de `1` a `4`. `1` son seis cajas y lo más barato que puede costar una muerte; `2` separa una manga de una mano. |
| `size`, `glow`, `light`, `y`, `face` | Como en cualquier display. |

La cabeza es la cabeza real, con cara y todo. El resto es el bloque más parecido al color que tiene de
verdad esa parte de la skin, y cada celda es un display — así que `detail:3` delante de mucha gente es
para lo que está el techo de displays.

Las poses antiguas siguen funcionando — `pose:burst`, `spread`, `knocked`, `vortex`, `balloon`,
`helicopter`, `plane`, `flatten`, `melt`, `sign` y `thrown` — con sus parámetros en
[Displays y NPCs](/docs/exylialib/displays-y-npcs).

<Callout type="tip" title="Cuadra el resto de la escena con los fotogramas">
Los fotogramas y las líneas `[DELAY]` cuentan los mismos segundos. En `SLAPPED` el cuerpo aguanta
entero `intact:0.1`, y el fotograma que le gira la cabeza de golpe empieza a 1,22 segundos de sus
fotogramas — 1,32 en total. El sonido de la bofetada va detrás de líneas `[DELAY]` que suman
exactamente 1,32. Esa es toda la diferencia entre un cuerpo que se encoge y un cuerpo al que golpean.
</Callout>

## `[NPC]` — un jugador falso entero

Ningún efecto de fábrica lo usa ya, pero sigue funcionando: una copia entera del jugador, con lo que
llevaba puesto, movida teletransportándola.

```yaml
- '[NPC] {victim};pose:lying;life:2.2;equip:true;face:false'
```

| Parámetro | Qué hace |
|---|---|
| *(la cabecera)* | `{victim}`, `{killer}`, o una textura en base64. Un **nombre** de jugador se rechaza: necesitaría una consulta que un efecto no puede esperar. |
| `pose` | `lying` por defecto. `pose_to` con `after` lo hace desplomarse a una segunda pose. |
| `life` | Segundos que se queda. Por defecto `5`. |
| `equip` | Si lleva lo que llevaba la víctima. Activado por defecto. |
| `face` | Si se orienta. Activado por defecto. |
| `from`, `to`, `over`, `ease`, `gravity`, `turn` | Cómo sale despedido o cómo cae. `over` por defecto `0.7` segundos. |
| `glow` | Un color de contorno. |
| `hurt` | Lanza el destello de daño. |
| `y` | Lo sube. |
| `spin` | Grados por segundo que sigue girando toda su vida — `turn` se acaba, `spin` no. |
| `bob`, `bob_every` | Bloques que sube y baja en bucle, y cuánto dura una subida y bajada. |
| `swing` | Segundos entre golpes de brazo. |
| `scale` | Cómo de grande se dibuja, siendo `1` el tamaño de un jugador. Necesita cliente 1.20.5. |
| `hold`, `offhand` | Un material en cada mano. |
| `pitch` | Inclinación de la cabeza en grados, negativo hacia arriba. |

Es un display, no una entidad: nadie puede golpearlo, saquearlo ni chocar con él.

## Cuando una línea está mal

Un paso que no se puede leer se descarta y se avisa en consola con la línea que lo causó — un token
desconocido, una partícula que no existe, una forma que no produjo puntos, un parámetro que el token
no entiende. El resto del efecto se lanza igual, así que una errata cuesta una línea y no el catálogo.

<Callout type="tip" title="El coste es por línea y por baja">
Un display es barato de animar — lo hace el cliente — pero cada línea sigue siendo un paquete por
espectador. Los efectos de fábrica rondan las veinte o treinta líneas, de tres a cinco segundos y
medio de principio a fin; ese techo es deliberado.
</Callout>
