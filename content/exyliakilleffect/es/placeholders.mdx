title: "Placeholders"
description: "El efecto del jugador, el del arma, la lista de favoritos y el modo de visibilidad."
---

Cada placeholder está escrito completo, y al hacer clic se copia.

## Lo que eligió el jugador

| Placeholder | Descripción |
|---|---|
| `%exyliakilleffect_effect%` | El id del efecto elegido. |
| `%exyliakilleffect_effect_name%` | Su nombre, con sus colores. |
| `%exyliakilleffect_effect_description%` | Su descripción, aplanada a una línea. |
| `%exyliakilleffect_effect_material%` | El material con el que se dibuja. |
| `%exyliakilleffect_effect_category%` | El id de la categoría. |
| `%exyliakilleffect_effect_category_name%` | El nombre de la categoría. |
| `%exyliakilleffect_effect_weapons%` | A qué se puede atar, en palabras. |
| `%exyliakilleffect_effect_tier%` | El id de su rareza. |
| `%exyliakilleffect_effect_tier_name%` | El nombre de la rareza. |
| `%exyliakilleffect_effect_tier_color%` | El color en que se escribe esa rareza. |
| `%exyliakilleffect_effect_tier_colour%` | El mismo color, con la `u`. |
| `%exyliakilleffect_has_effect%` | `true` o `false`. |

## Lo que lleva el arma en mano

Los mismos campos con `weapon_` delante. Responden sobre el objeto en la mano principal, no sobre la
elección del menú.

| Placeholder | Descripción |
|---|---|
| `%exyliakilleffect_weapon_effect%` | El id del efecto atado. |
| `%exyliakilleffect_weapon_effect_name%` | Su nombre. |
| `%exyliakilleffect_weapon_effect_description%` | Su descripción, en una línea. |
| `%exyliakilleffect_weapon_effect_material%` | Su material. |
| `%exyliakilleffect_weapon_effect_category%` | El id de su categoría. |
| `%exyliakilleffect_weapon_effect_category_name%` | El nombre de su categoría. |
| `%exyliakilleffect_weapon_effect_weapons%` | A qué encaja. |
| `%exyliakilleffect_weapon_effect_tier%` | El id de su rareza. |
| `%exyliakilleffect_weapon_effect_tier_name%` | El nombre de la rareza. |
| `%exyliakilleffect_weapon_effect_tier_color%` | El color en que se escribe esa rareza. |
| `%exyliakilleffect_weapon_effect_tier_colour%` | El mismo color, con la `u`. |
| `%exyliakilleffect_weapon_has_effect%` | `true` o `false`. |

## El resto

| Placeholder | Descripción |
|---|---|
| `%exyliakilleffect_visibility%` | Su modo de visibilidad, con el nombre que diga `particles.name-*`. |
| `%exyliakilleffect_favourites%` | Cuántos efectos tiene marcados. |
| `%exyliakilleffect_favorites%` | La misma cuenta, sin la `u`. |
| `%exyliakilleffect_favourite_<id>%` | `true` o `false` para un efecto — `%exyliakilleffect_favourite_blade_storm%`. |
| `%exyliakilleffect_favorite_<id>%` | La misma respuesta, sin la `u` — `%exyliakilleffect_favorite_blade_storm%`. |
| `%exyliakilleffect_random%` | `random` mientras cada baja saque un efecto distinto, `false` si no. |

## La caja

| Placeholder | Descripción |
|---|---|
| `%exyliakilleffect_keys%` | Cuántas llaves tiene. |
| `%exyliakilleffect_unlocked%` | Cuántos efectos ha ganado. |
| `%exyliakilleffect_catalogue%` | Cuántos declara el servidor. |
| `%exyliakilleffect_total%` | La misma cuenta, con el nombre corto. |
| `%exyliakilleffect_unlocked_<id>%` | `true` o `false` para un efecto — `%exyliakilleffect_unlocked_blade_storm%`. |
| `%exyliakilleffect_tier_count_<tier>%` | Cuántos efectos tiene una rareza — `%exyliakilleffect_tier_count_legendary%`. |

## Sin nada elegido

| Placeholder | Respuesta |
|---|---|
| `%exyliakilleffect_has_effect%` | `false` |
| `%exyliakilleffect_effect_description%` | Vacío |
| `%exyliakilleffect_effect_material%` | `BARRIER` |
| `%exyliakilleffect_effect_tier_color%` | Vacío |
| `%exyliakilleffect_effect_tier_colour%` | Vacío |
| Todo lo demás | Lo que diga `placeholders.none` — `None` por defecto |

Lo mismo vale para la familia `weapon_` cuando el arma no lleva nada, que es lo que los hace seguros
para un scoreboard sin fallback propio:

```yaml
lines:
  - " {muted}❙ {letters}Efecto: {highlight}%exyliakilleffect_effect_name%"
  - " {muted}❙ {letters}Arma: {highlight}%exyliakilleffect_weapon_effect_name%"
  - " {muted}❙ {letters}Llaves: {highlight}%exyliakilleffect_keys%"
  - " {muted}❙ {letters}Conseguidos: {highlight}%exyliakilleffect_unlocked%{muted}/%exyliakilleffect_catalogue%"
```

<Callout type="note" title="Con la elección aleatoria">
`%exyliakilleffect_effect%` responde `random` y `%exyliakilleffect_effect_name%` responde lo que diga
`menu.random-name`, así que un scoreboard lee "Random" en vez de leerse como si no llevara nada.
</Callout>

<Callout type="tip" title="effect_material es para menús">
Es el icono de lo que eligió, que es lo que permite que el menú de otro plugin dibuje su efecto actual
sin saber nada de este.
</Callout>
