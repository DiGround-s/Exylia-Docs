This guide leaves one arena running and playable. Everything is done from `/ffaadmin`; no YAML needs
editing.

## The minimum an arena needs

An arena is playable once it has a **region**, **at least one spawn** and **at least one kit**, and
is marked as enabled. Everything else is refinement.

<Steps>
  <Step title="Set the global lobby">
    Open `/ffaadmin` and set the lobby location. It is where a player returns after leaving any
    arena, and where they are sent on death if `leave-on-death` is on.
  </Step>
  <Step title="Create the arena">
    From the panel, create a new arena and give it a short identifier with no spaces, for example
    `nodebuff`. That identifier is what you use in commands and placeholders.
  </Step>
  <Step title="Mark the region">
    Select the two corners of the combat area and save them as the arena's region. The region defines
    what counts as "inside": leaving it returns the player to spawn.
  </Step>
  <Step title="Add a spawn">
    Stand where you want players to appear and create the spawn from the spawn menu. Create more than
    one and players will be able to choose on entry.
  </Step>
  <Step title="Create a kit">
    Equip exactly what you want to hand out and save the kit from the kit menu. Inventory, armour and
    offhand are all stored.
  </Step>
  <Step title="Enable the arena">
    In the arena's settings menu, switch it on. From that moment it shows up in `/ffa`.
  </Step>
  <Step title="Test it">
    Run `/ffa join nodebuff`, or just `/ffa` and pick it from the menu.
  </Step>
</Steps>

## What happens on join

When `/ffa join <arenaId>` runs, the plugin decides how many menus to show:

- If the arena has **more than one spawn**, the spawn selector opens.
- If on top of that the kit mode is `SELECTABLE` and there is **more than one kit**, the kit selector
  opens.
- If there is only one of each, the player goes straight in.

<Callout type="tip">
That logic is exposed in the API too: `FFAAPI.joinFFA`, `joinFFAWithSpawn` and `joinFFAWithKit` are
exactly those three steps. See [API](/docs/exyliaffa/api).
</Callout>

## Recommendations for a first arena

| Setting | Suggestion | Why |
|---|---|---|
| `max-players` | 30–50 | Enough to feel alive without turning into chaos. |
| Protection radius | 3–5 blocks | Stops spawn-killing without making spawn untouchable. |
| Regeneration | 0 at first | Turn it on once the arena has blocks that get broken. |
| `reset-kit-after-kill` | On for nodebuff | Rewards the kill and prevents accumulated advantage. |
| Save inventory on leave | On | Hands the player back what they had before joining. |
