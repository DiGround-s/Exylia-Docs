## The file

Two sections: the categories, and the effects that belong to them. An effect's `effects` block is a
map of **triggers**, not a list.

```yaml title="effects.yml"
categories:
  ember:
    material: BLAZE_POWDER
    name: 'Ember'
    priority: 1

arrow_effects:
  EMBER_TRAIL:
    category: ember
    name: "<gradient:#FFD08A:#C43A10><bold>EMBER TRAIL</bold></gradient>"
    material: BLAZE_ROD
    description: "Coals come off the shaft, {highlight}tumble, and burn out{neutral} behind it."
    priority: 1
    trail-interval: 1
    effects:
      trail:
        - '[DISPLAY] MAGMA_BLOCK;as:block;size:0.09;size_to:0.01;life:0.45;spin:1,1,1;gravity:2;light:15;glow:{warning}'
        - '[PARTICLE] FLAME;count:2;offset:0.04,0.04,0.04;speed:0.01'
      hit:
        - '[SOUND] BLOCK_FIRE_EXTINGUISH;0.7;1.3'
        - '[CIRCLE] MAGMA_BLOCK;as:block;radius:0.2;points:10;size:0.1,0.05,0.1;size_to:0.5,0.04,0.5;pull:-2;ease:out;life:0.45;y:0.05;light:15;glow:{warning}'
        - '[PARTICLE] FLAME;count:14;offset:0.4,0.2,0.4;speed:0.05'
```

| Key | What it does |
|---|---|
| `category` | Which tab it appears under. Must be a key declared under `categories`. |
| `name` | What menus and placeholders call it. |
| `material` | The item the row is drawn with. |
| `description` | A list is one line per entry; a single string breaks on `<nl>`. |
| `priority` | Where it sits in its tab; lower comes first. |
| `trail-interval` | Ticks between trail steps. `1` is every tick, `2` every other. Defaults to `trail.default-interval`. |
| `effects` | The triggers, below. |
| `bows` | Optional. What it may be bound to. |
| `projectiles` | Optional. Which projectiles it plays on; without it `config.yml` decides. |

## The triggers

| Trigger | When |
|---|---|
| `launch` | The shot leaving the bow. |
| `trail` | Along the flight, every `trail-interval` ticks. |
| `hit` | Wherever it lands, whatever it hit. |
| `hit-entity` | Only on something alive — falls back to `hit`. |
| `hit-block` | Only on a block — falls back to `hit`. |

`hit-entity` and `hit-block` are the same moment told apart: declare them when landing on a player and
landing on the ground deserve different pictures. Written either way — `hit-entity` or `hit_entity` —
because a hyphen is what every other Exylia file writes.

<Callout type="warning" title="The trail is the one with a budget">
An arrow lives about forty ticks, and four archers are four arrows in the air. Whatever `trail` writes
is drawn on **every one of those ticks, per shot**: one or two small displays plus a particle line for
the glow, and no sound. The impact is the payoff and is allowed to be one — under a second, a dozen
displays at the very most.
</Callout>

## `bows`

Only read while `behaviour.mode` reads bows. It accepts item names and families:

```yaml
bows: [ CROSSBOW, TRIDENT ]
```

| Family | Matches |
|---|---|
| `ANY` | Anything at all. |
| `BOW`, `CROSSBOW`, `TRIDENT` | Just that item. |
| `RANGED` | Bows, crossbows and tridents. |

None of the shipped effects declares `bows`, so out of the box every one of them fits everything.

<Callout type="note" title="The effect id is the permission">
`EMBER_TRAIL` is `exyliarrows.effect.ember_trail`. Renaming the key renames the node. Case is not part
of it: ids are lowercased on the way in.
</Callout>

<Callout type="tip" title="NULL is an effect, not a mistake">
The void category has one called `NULL`. YAML reads that key as nothing at all unless it is quoted, so
leave it exactly as the file writes it if you are editing around it.
</Callout>

## Writing your own

<Steps>
  <Step title="Add the entry">
    A new key under `arrow_effects`, with a `category` that exists and an `effects` block naming at
    least one trigger.
  </Step>
  <Step title="Spend where it shows">
    Keep the trail to a display or two; put the work in `hit`. The full step syntax is in
    [Sequences](/docs/exyliaarrows/sequences).
  </Step>
  <Step title="Reload">
    `/arrowsadmin reload`.
  </Step>
  <Step title="Look at it">
    `/arrows preview <id>` plays it against an empty sky, then puts you back.
  </Step>
  <Step title="Grant it">
    `exyliarrows.effect.<id in lowercase>`, or the whole category.
  </Step>
</Steps>
