title: "Placeholders"
description: "El efecto del jugador, el del arco, la lista de favoritos, la colección y el modo de visibilidad."
---

Cada placeholder está escrito completo, y al hacer clic se copia.

## Lo que eligió el jugador

| Placeholder | Descripción |
|---|---|
| `%exyliarrows_effect%` | El id del efecto elegido. |
| `%exyliarrows_effect_name%` | Su nombre, con sus colores. |
| `%exyliarrows_effect_description%` | Su descripción, aplanada a una línea. |
| `%exyliarrows_effect_material%` | El material con el que se dibuja. |
| `%exyliarrows_effect_category%` | El id de la categoría. |
| `%exyliarrows_effect_category_name%` | El nombre de la categoría. |
| `%exyliarrows_effect_bows%` | A qué se puede atar, en palabras. |
| `%exyliarrows_effect_tier%` | El id de su rareza. |
| `%exyliarrows_effect_tier_name%` | El nombre visible de la rareza. |
| `%exyliarrows_effect_tier_color%` | El color en el que se escribe la rareza. |
| `%exyliarrows_effect_tier_colour%` | El mismo color, con la `u`. |
| `%exyliarrows_has_effect%` | `true` o `false`. |

## Lo que lleva el arco en mano

Los mismos campos con `bow_` delante. Responden sobre el objeto en la mano principal, no sobre la
elección del menú.

| Placeholder | Descripción |
|---|---|
| `%exyliarrows_bow_effect%` | El id del efecto atado. |
| `%exyliarrows_bow_effect_name%` | Su nombre. |
| `%exyliarrows_bow_effect_description%` | Su descripción, en una línea. |
| `%exyliarrows_bow_effect_material%` | Su material. |
| `%exyliarrows_bow_effect_category%` | El id de su categoría. |
| `%exyliarrows_bow_effect_category_name%` | El nombre de su categoría. |
| `%exyliarrows_bow_effect_bows%` | A qué encaja. |
| `%exyliarrows_bow_effect_tier%` | El id de su rareza. |
| `%exyliarrows_bow_effect_tier_name%` | El nombre de la rareza. |
| `%exyliarrows_bow_effect_tier_color%` | El color en el que se escribe esa rareza. |
| `%exyliarrows_bow_effect_tier_colour%` | El mismo color, con la `u`. |
| `%exyliarrows_bow_has_effect%` | `true` o `false`. |

## El resto

| Placeholder | Descripción |
|---|---|
| `%exyliarrows_visibility%` | Su modo de visibilidad, con el nombre que diga `particles.name-*`. |
| `%exyliarrows_favourites%` | Cuántos efectos tiene marcados. |
| `%exyliarrows_favorites%` | La misma cuenta, sin la `u`. |
| `%exyliarrows_favourite_<id>%` | `true` o `false` para un efecto — `%exyliarrows_favourite_ember_trail%`. |
| `%exyliarrows_favorite_<id>%` | La misma respuesta, sin la `u` — `%exyliarrows_favorite_ember_trail%`. |
| `%exyliarrows_random%` | `random` mientras cada disparo saque un efecto distinto, `false` si no. |
| `%exyliarrows_keys%` | Llaves de caja que tiene. |
| `%exyliarrows_unlocked%` | Cuántos efectos ganó en la caja. |
| `%exyliarrows_unlocked_<id>%` | `true` o `false` para un efecto — `%exyliarrows_unlocked_ember_trail%`. |
| `%exyliarrows_catalogue%` | Cuántos efectos declara el servidor. |
| `%exyliarrows_total%` | La misma cuenta, con el nombre corto. |
| `%exyliarrows_tier_count_<id>%` | Cuántos efectos tiene una rareza — `%exyliarrows_tier_count_legendary%`. |

<Callout type="note" title="El aleatorio responde como sí mismo">
Mientras un jugador está en aleatorio, `%exyliarrows_effect%` responde `random` y
`%exyliarrows_effect_name%` responde `menu.random-name` — si no, un scoreboard que pregunte qué lleva
leería que no lleva nada.
</Callout>

## Sin nada elegido

| Placeholder | Respuesta |
|---|---|
| `%exyliarrows_has_effect%` | `false` |
| `%exyliarrows_effect_description%` | Vacío |
| `%exyliarrows_effect_material%` | `BARRIER` |
| `%exyliarrows_effect_tier_color%` | Vacío |
| `%exyliarrows_effect_tier_colour%` | Vacío |
| Todo lo demás | Lo que diga `placeholders.none` — `None` por defecto |

Lo mismo vale para la familia `bow_` cuando el arco no lleva nada, que es lo que los hace seguros
para un scoreboard sin fallback propio:

```yaml
lines:
  - " {muted}❙ {letters}Efecto: {highlight}%exyliarrows_effect_name%"
  - " {muted}❙ {letters}Arco: {highlight}%exyliarrows_bow_effect_name%"
```

<Callout type="tip" title="effect_material es para menús">
Es el icono de lo que eligió, que es lo que permite que el menú de otro plugin dibuje su efecto actual
sin saber nada de este.
</Callout>
