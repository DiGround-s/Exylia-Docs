title: "Introducción"
description: "Qué es ExyliaEvents, los cuarenta y nueve minijuegos que registra y cómo está organizada la documentación."
---

ExyliaEvents es un sistema de eventos de minijuegos. Registra **49 tipos de evento** — cuarenta y dos
juegos y siete variantes por equipos — y cada uno es un juego real y distinto, con sus reglas, su
pantalla de ajustes, su scoreboard y sus mensajes.

Una *configuración de evento* es una arena de un tipo: su lobby, sus spawns, sus límites, sus
ajustes, sus kits y sus recompensas. Puedes tener tantas como quieras, y varias pueden correr a la
vez. Todo se crea desde `/eventsadmin`, y las configuraciones viven en la base de datos, no en un
archivo.

## Requisitos

| Requisito | Detalle |
|---|---|
| Servidor | Paper 1.21 o superior. Folia soportado. |
| Java | 21 |
| Dependencias obligatorias | `ExyliaLib`, `FastAsyncWorldEdit`, `packetevents` |
| Dependencias opcionales | `PlaceholderAPI`, `ViaVersion`, `Worlds`, `WorldGuard`, Apollo o Feather, `TAB`, `floodgate` |

<Callout type="note" title="FastAsyncWorldEdit es obligatorio, no opcional">
Las esquemáticas de arena son la forma de restaurar una arena tras una partida y de que Brackets y
Build Battle se clonen. Sin FAWE el plugin no arranca.
</Callout>

## Dónde vive cada cosa

| Cosa | Dónde |
|---|---|
| Configuraciones de evento, arenas, ajustes, recompensas | Base de datos (`event_configurations`) |
| Kits, tablas de loot, inscripciones, recompensas pendientes | Base de datos |
| Estadísticas de jugador, globales y por evento | Base de datos |
| Temporizadores, límites, cooldowns, boss bars, música | `config.yml` |
| Sidebars, uno por tipo de evento | `scoreboards.yml` |
| Todos los mensajes | `messages.yml` |
| Temas de Build Battle | `buildbattle-themes.yml` |
| Preguntas de Trivia | `trivia-questions.yml` |
| Series de gauntlet | Base de datos (`event_gauntlets`) |
| Diseño de los menús | `menus/` |
