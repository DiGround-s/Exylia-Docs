ExyliaEvents is a minigame event system. It registers **49 event types** — forty-two games and seven
team variants — and each one is a real, separate game with its own rules, its own settings screen, its
own scoreboard and its own messages.

An *event configuration* is one arena of one type: its lobby, its spawns, its bounds, its settings,
its kits and its rewards. You can have as many as you like, and several can run at the same time.
Everything is created from `/eventsadmin`, and configurations live in the database rather than in a
file.

## What it covers

<Cards>
  <Card title="49 event types" href="/docs/exyliaevents/event-types">

  </Card>

## Requirements

| Requirement | Detail |
|---|---|
| Server | Paper 1.21 or newer. Folia supported. |
| Java | 21 |
| Required dependencies | `ExyliaLib`, `FastAsyncWorldEdit`, `packetevents` |
| Optional dependencies | `PlaceholderAPI`, `ViaVersion`, `Worlds`, `WorldGuard`, Apollo or Feather, `TAB`, `floodgate` |

<Callout type="note" title="FastAsyncWorldEdit is required, not optional">
Arena schematics are how an arena is restored after a game and how Brackets and Build Battle clone
themselves. Without FAWE the plugin does not start.
</Callout>

## Where things live

| Thing | Where |
|---|---|
| Event configurations, arenas, settings, rewards | Database (`event_configurations`) |
| Kits, loot tables, sign-ups, pending rewards | Database |
| Player statistics, global and per event | Database |
| Timers, limits, cooldowns, boss bars, music | `config.yml` |
| Sidebars, one per event type | `scoreboards.yml` |
| Every message | `messages.yml` |
| Build Battle themes | `buildbattle-themes.yml` |
| Trivia questions | `trivia-questions.yml` |
| Gauntlet series | Database (`event_gauntlets`) |
| Menu layouts | `menus/` |
