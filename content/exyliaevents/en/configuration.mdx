Files live in `plugins/ExyliaEvents/`. All are written on the first boot with their defaults and with
comments on each key.

## config.yml

### settings

Everything about how events behave, covered in [Game flow](/docs/exyliaevents/game-flow):

```yaml
settings:
  use-main-lobby: true
  broadcast-interval: 30
  waiting-timeout: 300
  broadcast-countdown-times: [30, 15, 10, 5]
  max-events-per-player: 1
  max-events-total: -1
  max-events-waiting: 3
  start-cooldown: 0
  start-cooldown-permissions: []
  event-music-enabled: true
  event-music-volume: 0.5
  event-music-interval: 150
  event-music-discs: [...]
```

<Field name="use-main-lobby" type="boolean" defaultValue="true">
Whether players are sent to the stored main lobby when they leave an event.
</Field>

<Field name="frozen-timeout" type="integer" defaultValue="6">
Seconds a player may hang motionless in mid-air inside an event before being eliminated from it. A
frozen or lag-switched client stops sending movement and keeps floating where it stopped, which no
player can do on their own. Standing still on the ground, swimming, climbing, riding and gliding are
not counted. `0` turns it off.
</Field>

### network

```yaml
network:
  enabled: false
  return-on-end: true
```

Whether this server announces its events to the rest of the network and accepts the players other
servers send to them. Off by default, and covered in [Network](/docs/exyliaevents/network).

### main-lobby

A leftover from an older layout. The lobby lives in the database now; this section is read once, on
the first start after the move, and copied there. A blank world means there is nothing to copy.

### Chat

```yaml
settings:
  chat-isolation: true
```

Keeps an event's chat inside that event: its players read each other and nobody else, spectators read
the players, and the rest of the server reads neither. Spectators are the one asymmetry — the players
never read them, so a running match is not commentated at.

Set it to `false` to leave chat exactly as the server's chat plugin delivers it. The message is never
cancelled or re-sent, only its audience is smaller, and a chat plugin that sends each line itself has
taken delivery over — isolation then quietly does not apply.

<Callout type="tip" title="Times on the admin screens are typed">
Durations — an event's base length, the CS:GO round clocks, the Mace Roulette timers — are asked for
as a length of time rather than clicked up a step at a time, and are written back the same way.
</Callout>

## messages.yml

Every message, with a shared `events` section and then one section per event type — `tnttag`,
`taggame`, `lms`, `topkiller`, `oitc`, `quake`, `csgo`, `tntrun`, `spleef`, `splegg`, `splatoon`,
`brackets`, `tournament`, `buildbattle`, `blockparty`, `thimble`, `parkour`, `infection`, `kingkong`,
`slap`, `anvilrunning`, `chairs`, `gemcrawler`, `pillarsoffortune`, `simonsays`, `volcano`,
`survivalgames`, `bridge`, `ctf`, `domination`, `murdermystery`, `hideseek`, `redlight`,
`glassbridge`, `koth`, `paintball`, `dodgeball`, `sheepwars`, `zombiehorde`, `trivia`, `race`,
`maceroulette`, the seven team variants and `gauntlet` — plus `teams`, `placeholders` and `admin`.

Team names live in `teams`, which is why translating the file translates the teams as well.

## scheduled-events.yml

Time-of-day scheduling. See
[Game flow · Scheduled events](/docs/exyliaevents/game-flow#scheduled-events).

## trivia-questions.yml

The questions Trivia asks. Every entry has its text, exactly four answers and `correct`, the index of
the right one counted from zero — which is what the four answer zones marked on the arena are matched
against.

```yaml title="trivia-questions.yml"
questions:
  - question: "How many blocks tall is an Enderman?"
    answers: ["2", "3", "4", "5"]
    correct: 1
```

It ships with ten example questions and is meant to be rewritten, translated or replaced wholesale. A
malformed question — not four answers, or a `correct` out of range — is dropped.

## buildbattle-themes.yml

The themes Build Battle votes on, plus the materials the vote items use. Fully translatable: edit,
translate or replace every entry. The settings menu has a button that restores the shipped list.

## menus/

```text
menus/
├── admin/    the panel, the type selector, the configuration list and setup,
│             one settings screen per type — CS:GO has one per weapon and Mace
│             Roulette one for its modifiers —, kit list, arena markers, the
│             gauntlet editor and confirmation dialogs
└── user/     the main menu, active events, start event, stats, kit selection,
    └── es/   team selection, the gauntlet builder and the spectator menu
              (Spanish copies)
```

## Migrations

`config.yml` is at version 2. A file from version 1 is migrated on the first boot after updating: the
three title timings are divided by twenty, because they were written in ticks and are read in seconds
now.

<Callout type="warning" title="Unknown keys are removed">
A key no file declares is deleted on load and reported once as `UNKNOWN_KEY`. It keeps the files clean
across updates, and is why your own keys do not survive in them.
</Callout>
