---
title: "Placeholders"
description: "The nine placeholders the plugin registers, and the sidebar names that are not placeholders at all."
---

Every placeholder below is written in full, and clicking one copies it.

They are registered through ExyliaLib as one group per subject, so the registered name of the total
player count is `total_players`, and PlaceholderAPI reaches a registered name by putting the plugin in
front of it. A scoreboard, a hologram or a chat plugin asks for `%exyliasandbox_total_players%`, which
is the form this page uses throughout; inside an Exylia plugin's own files the registered name stands
on its own.

## Players in the worlds

| Placeholder | Description |
|---|---|
| `%exyliasandbox_total_players%` | Players across every **loaded** sandbox world |
| `%exyliasandbox_world_players_<world>%` | Players in one world. `0` for an unknown or unloaded world |

The `<world>` is a world id as it appears in the admin panel, not a Bukkit world name.

## The queue

| Placeholder | Description |
|---|---|
| `%exyliasandbox_queue_total%` | Players waiting in every queue |
| `%exyliasandbox_queue_world_<world>%` | The **name of the player who has waited longest** in that world's queue, or `N/A` |

<Callout type="warning" title="`queue_world` is a name, not a count">
It answers with a player name so a lobby board can advertise who is waiting for an opponent. For a
count per world there is no placeholder; `%exyliasandbox_queue_total%` is the only number.
</Callout>

## The viewer's statistics

| Placeholder | Description |
|---|---|
| `%exyliasandbox_sandbox_kills%` | Kills in sandbox worlds |
| `%exyliasandbox_sandbox_deaths%` | Deaths in sandbox worlds |
| `%exyliasandbox_sandbox_kdr%` | Kills divided by deaths, two decimals. With no deaths it is the kill count |
| `%exyliasandbox_sandbox_playtime%` | Time spent in sandbox worlds, written out — `1h 5m 3s` |
| `%exyliasandbox_sandbox_playtime_seconds%` | The same number, in seconds |

These five need a viewer, so they resolve to nothing in a context with no player attached. Playtime
includes the session the player is in right now, not only what has been written to the database.

<Callout type="note" title="A name with no answer resolves to nothing, not to an empty string">
Which means the fallback syntax works: `%exyliasandbox_queue_world_plains|nobody%`.
</Callout>

## The sidebar names are different

The lines in `scoreboards.yml` are drawn from the board's own data, not from the placeholders above.
Inside that file:

| Name | Meaning |
|---|---|
| `%world%` | The display name of the world the viewer is in |
| `%players%` | Players in that world |
| `%border%` | The border **radius** of that world |
| `%kills%`, `%deaths%`, `%kdr%` | The viewer's statistics |
| `%sandbox_playtime%` | The registered playtime resolver, written without the plugin prefix |

Writing `%playtime%` there shows the text literally: the registered name is `sandbox_playtime`.
