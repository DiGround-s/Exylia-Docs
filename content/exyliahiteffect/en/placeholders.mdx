Every placeholder below is written in full, and clicking one copies it.

## What the player chose

| Placeholder | Description |
|---|---|
| `%exyliahiteffect_effect%` | The chosen effect's id. |
| `%exyliahiteffect_effect_name%` | Its display name, with its colours. |
| `%exyliahiteffect_effect_description%` | Its description, flattened to one line. |
| `%exyliahiteffect_effect_material%` | The material it is drawn with. |
| `%exyliahiteffect_effect_category%` | The category id. |
| `%exyliahiteffect_effect_category_name%` | The category's display name. |
| `%exyliahiteffect_effect_weapons%` | What it may be bound to, in words. |
| `%exyliahiteffect_effect_tier%` | Its rarity id. |
| `%exyliahiteffect_effect_tier_name%` | The rarity's display name. |
| `%exyliahiteffect_effect_tier_color%` | The colour that rarity is written in. |
| `%exyliahiteffect_effect_tier_colour%` | The same colour, with the `u`. |
| `%exyliahiteffect_has_effect%` | `true` or `false`. |

## What the weapon in hand carries

The same fields, with `weapon_` in front. They answer about the item in the player's main hand, not
about their menu choice.

| Placeholder | Description |
|---|---|
| `%exyliahiteffect_weapon_effect%` | The bound effect's id. |
| `%exyliahiteffect_weapon_effect_name%` | Its display name. |
| `%exyliahiteffect_weapon_effect_description%` | Its description, on one line. |
| `%exyliahiteffect_weapon_effect_material%` | Its material. |
| `%exyliahiteffect_weapon_effect_category%` | Its category id. |
| `%exyliahiteffect_weapon_effect_category_name%` | Its category name. |
| `%exyliahiteffect_weapon_effect_weapons%` | What it fits. |
| `%exyliahiteffect_weapon_effect_tier%` | Its rarity id. |
| `%exyliahiteffect_weapon_effect_tier_name%` | The rarity's display name. |
| `%exyliahiteffect_weapon_effect_tier_color%` | The colour that rarity is written in. |
| `%exyliahiteffect_weapon_effect_tier_colour%` | The same colour, with the `u`. |
| `%exyliahiteffect_weapon_has_effect%` | `true` or `false`. |

## The rest

| Placeholder | Description |
|---|---|
| `%exyliahiteffect_visibility%` | The player's visibility mode, named as `particles.name-*` says. |
| `%exyliahiteffect_favourites%` | How many effects they have starred. |
| `%exyliahiteffect_favorites%` | The same count, without the `u`. |
| `%exyliahiteffect_favourite_<id>%` | `true` or `false` for one effect — `%exyliahiteffect_favourite_crit_spark%`. |
| `%exyliahiteffect_favorite_<id>%` | The same answer, without the `u` — `%exyliahiteffect_favorite_crit_spark%`. |
| `%exyliahiteffect_keys%` | How many crate keys they hold. |
| `%exyliahiteffect_unlocked%` | How many effects they have won. |
| `%exyliahiteffect_unlocked_<id>%` | `true` or `false` for one effect — `%exyliahiteffect_unlocked_crit_spark%`. |
| `%exyliahiteffect_catalogue%` | How many effects the server declares. |
| `%exyliahiteffect_total%` | The same count, under the shorter name. |
| `%exyliahiteffect_tier_count_<id>%` | How many effects a rarity holds — `%exyliahiteffect_tier_count_legendary%`. |
| `%exyliahiteffect_random%` | `random` while every hit is drawing a different effect, `false` otherwise. |

## On the random choice

A player who asked for a different effect on every hit is not carrying one, and a scoreboard asking
what they carry would otherwise read as carrying nothing. So `%exyliahiteffect_effect%` answers
`random`, `%exyliahiteffect_effect_name%` answers whatever `menu.random-name` says, and
`%exyliahiteffect_has_effect%` stays `true`.

## With nothing chosen

| Placeholder | Answer |
|---|---|
| `%exyliahiteffect_has_effect%` | `false` |
| `%exyliahiteffect_effect_description%` | Empty |
| `%exyliahiteffect_effect_material%` | `BARRIER` |
| `%exyliahiteffect_effect_tier_color%` | Empty |
| `%exyliahiteffect_effect_tier_colour%` | Empty |
| Everything else | Whatever `placeholders.none` says — `None` by default |

The same applies to the `weapon_` family when the weapon carries nothing, which is what makes them
safe to drop into a scoreboard with no fallback of their own:

```yaml
lines:
  - " {muted}❙ {letters}Effect: {highlight}%exyliahiteffect_effect_name%"
  - " {muted}❙ {letters}Weapon: {highlight}%exyliahiteffect_weapon_effect_name%"
```

<Callout type="tip" title="effect_material is for menus">
It is the icon of whatever they chose, which is what lets another plugin's menu draw their current
effect without knowing anything about this one.
</Callout>
