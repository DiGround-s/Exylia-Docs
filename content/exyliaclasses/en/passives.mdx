---
title: "Passives"
description: "Effects held for as long as the class is worn, and effects held only while a condition is true."
---

## Passive effects

A flat list of effect lines, applied when the class activates and taken back when it is removed.

```yaml
passive-effects:
  - SPEED|3
  - DAMAGE_RESISTANCE|2
```

They are always applied **infinite**, whatever duration the line carries, and removed by name — so a
class ending never clears potion effects a player got from somewhere else.

They are re-applied when a player is saved by a totem of undying, which would otherwise strip them.

<Callout type="warning" title="Effects are removed by name, not by source">
A Rogue's permanent `INVISIBILITY|1` and an invisibility potion the player drank are the same effect.
Leaving the class removes it, potion included.
</Callout>

## Special passives

Effects held only while a condition is true. They are checked **once a second** for every player in a
class that declares them: the effects go on the moment the condition becomes true and come off the
moment it stops being true.

```yaml
special-passives:
  - type: "BELOW_Y"
    condition: "40"
    effects:
      - INVISIBILITY|1
```

| Key | What it is |
|---|---|
| `type` | The condition type. `BELOW_Y` is the only one. |
| `condition` | The value the type reads. For `BELOW_Y`, a Y coordinate. |
| `effects` | Effect lines, applied infinite while the condition holds. |

| Type | True when |
|---|---|
| `BELOW_Y` | The player's Y is strictly below `condition`. A `condition` that is not a number is always false. |

An unknown `type` is logged and the entry is dropped.

The list takes more than one entry, and each is tracked separately:

```yaml
special-passives:
  - type: "BELOW_Y"
    condition: "40"
    effects:
      - INVISIBILITY|1
  - type: "BELOW_Y"
    condition: "0"
    effects:
      - FIRE_RESISTANCE|1
      - NIGHT_VISION|1
```

The Miner ships with the first of those two — invisible below Y 40. The second is the same idea one
layer deeper.

<Callout type="note" title="They come off with the class">
Everything a special passive granted is removed when the class is removed, along with the ordinary
passives — including if the player dies or logs out while the condition is true.
</Callout>
